# 局部改稿依赖检查

这是基于三套完整案例的文字级改稿依赖说明，未生成新图像或视频。v1.1区分完整导演稿与精简执行稿：修改动作后必须补写受影响镜头的`execution`窗口、相邻镜状态、段内时码和关键帧，不能只传播一个结局字段。实际行为试用结果另见`../VERIFICATION.md`。

## 1. 将“救援脱身”改为“两人在门外被截住”

基于02例。不能只改 `design.outcome`，因为最后镜头和关键帧仍明确插栓、脱身。

需先明确截住的既有手段是否存在：当前岳衡不能离坛、第二脉冲固定落东眼，不能突然隔墙抓人。可在本场假设中增加可观察且有代价的门锁控制，提前在读阵拍让闻栖看见并误判；或延迟解扣让护符三秒不够关门。两种方式不能随意混用。

选择“解扣延迟”时，更新解扣拍、旁路维持极限后的后果、转移时间、护符启用、门槛动作和最后镜头终态；重排时长或减少无因果停留。修改所有受影响关键帧姿态和时刻，以及后两段起终状态、视频稿与设计卡。角色外观ID和北坛资产不重建。

通过标准：结局由已铺条件导致，岳衡不凭空获得能力；旧“门栓到位”帧失效，不继续作为末帧参考。

## 2. 取消慢镜

三套默认案例未依赖慢镜，不为取消慢镜额外加删动作。v1.1新增的独立行为试用允许使用慢镜检验同窗同步，和默认三例区分记录。

若后续把01的接点扩展为慢镜，所有JSON时间仍为成片时间；说明该成片窗口延展的动作阶段与其他人物同步方式。取消时恢复正常观察速度、重新分配成片窗口，更新接点时刻、镜头、关键帧、execution.cues及制作段映射。不能只删“慢镜”二字，也不能将成片秒数当作真实世界经过时间。

## 3. 将飞剑替换为不能转弯的直射法锥

基于01例。不仅改法宝名称与外形：原回召拍依赖经过南端缺口再折返，直射法锥无法按原路线拦棍，现有结局失去前提。

需要保留结局时，重新设计回防手段，例如让秦砚先退到能直线收器的位置，同时给杜彻合理追击；检查退路距离、右肘自由、节点用途、镜头可见性与总时长。更新资产尺度与接点、动作路径、镜头起终态、所有出现器物的关键帧及视频稿。仅外观未变的角色资产继续复用。

通过标准：新器物按自身机制成立，旧弯折路线和剑脊接点不残留。若无法同时保留原结局和总时长，列出具体冲突，而不静默修改硬要求。

## 4. 继承一张角色图，但当前无法访问

使用03例的沈照作为修改对象。登记来源和“外观待核实”，先保留现有动作设计；不声称图里确有墨绿长衣、银扣或灰羽扇。不把未知图片描述成已读取事实。

能独立推进的部分是目标、能力和空间推演。需要身份锚点的最终资产图提示词、关键帧和每段视频稿明确待素材核实，不伪造已经完成素材一致性验收。若用户文字明确提供了服装与器物，可依据文字继续，并注明观察依据。

读取素材后仅更新实际冲突的外观与绑定；若图中器物形态影响握持或攻防，再反查动作链。纯配色修改不要求重写整场。
