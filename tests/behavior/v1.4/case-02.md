# 用户请求

只写一个单人疗伤短镜的视频提示词，必要时补一张参考帧说明。角色坐在廊下，右掌伤口逐步闭合，从不能屈指到重新握住杯子；不需要打架，结尾仍有浅疤。

# 答复

```text
约11秒，单人疗伤，一镜到底。角色坐在廊下矮桌旁，左手安放在左膝，右前臂由桌沿承托，右掌朝上，掌根近拇指一侧的裂口清楚可见，手指僵直；一只小杯放在右手旁的桌面。固定侧前方手部近景，保留胸口下缘、右前臂、整只右手与杯子，掌根和指节都在焦内。开始他尝试屈指，指尖只轻颤便停住。随后缓缓吐息，伤缘浮起一线柔和微光，光沿裂口两侧向内推进：伤口逐段收窄、两侧皮肤贴合，裂口深处依次闭合，最后只剩一条浅色细疤；微光仅照亮掌纹与邻近指侧。伤口闭合后，食指先小幅弯曲，其他手指依次恢复屈伸，再把右掌缓慢转向杯子，五指确实环住杯身，将杯子稳稳提离桌面一指高。结尾停留在真实握持的接点，拇指根下露出的掌根浅疤仍可见，皮肤纹理没有变成全新无痕状态。廊外散射天光保持稳定，疗伤微光逐渐退去；只保留檐下风声、呼吸声与杯底离桌的轻响。
```
