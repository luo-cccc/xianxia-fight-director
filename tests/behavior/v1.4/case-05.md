# 用户请求

设计水镜特效转场：人物在同一座石桥上始终不移动，镜头从他的真实脸庞向下进入水面倒影，再从倒影内部抬起看到桥底倒悬的封印阵。只改变观看位置，不赋予人物传送能力。给视频生成提示词、必要参考职责和主要验收点。

# 答复

水镜只承担观看位置的光学连接。真实人物一直留在桥面，封印阵原本就倒悬在桥底，镜头把它揭示出来。

**视频生成提示词**

```text
约13秒，一条连续的水镜转场。仅一名人物站在同一座石桥临水侧石栏内，双脚贴着同一对石砖，身体和持物姿态全程不移动。桥侧有一根缺角栏柱、拱腹三道浅石缝，作为贯穿视点变化的地标。桥下河面平缓，只有细小流纹；一道水平圆形封印阵原已倒悬于桥腹，阵面朝向水面，三处连接点固定在桥底石缝，位置始终不变。
开头从桥外侧、栏杆上方的机位近看人物真实脸庞，背景保留缺角栏柱；先用短暂停留确认这是真实人物。随后镜头沿桥的外缘缓缓下降并向下俯视，从栏外开放空间接近水面，连续带出栏柱、桥侧与人物的水中倒影；镜头不穿过石栏或桥体。真实脸庞退出上沿，水里的脸部倒像逐渐占满画面，倒像只随水纹轻微弯曲，姿态、服饰和持物对应桥上的同一个人。倒影旁保留同一缺角栏柱的反像与桥拱弧线。
镜头继续贴近脸部倒影，细波从画面边缘掠过，进入倒影内部的观看位置。水面反射作为光学转场的连接面：桥拱倒像沿同一拱线连续衔接到桥下低位视角，水线与石缝的对应关系保持可追踪；只有观看位置改变。接着镜头沿桥拱下方的开放空间轻移并向上抬仰，从倒影内部抬起，看见真实桥腹下方、阵面朝下的封印圆阵。圆阵的三处连接点、桥底石缝与下方水面同框，停留读清它倒悬在同一座桥下。阵的微弱冷光照到邻近桥腹，并在水面留下对应反光，阵体不移动、不新生。尾部构图在桥侧上缘保留缺角栏柱及人物仍在原处的局部轮廓，证明桥上位置没有改变。声音从脸旁的近风声平顺转为桥下水声与拱腹回响；不出现人物入水、身体溶解、额外镜中人或穿出出口的动作。
```

**必要参考职责**

- **桥侧空间关系图，一张。** 依据本条文字制作侧视布局，明确桥面人物站点、缺角栏柱、桥拱、水线、桥底圆阵及朝下阵面，画出镜头沿桥外缘下降、从拱口下方抬仰的开放路径。只约束空间、尺度与连接点，不锁人物表情或整段镜头姿态。
- **倒影内部中间态目标，一张。** 水中脸部倒像占主要画面，旁边带同一栏柱反像和桥拱弧线，细波只局部扭曲成像；这是桥上人物的一个倒影，不画第二个实体。只约束成像关系与转场接续锚点，不把静图当作连续转场已成立的证据。

已有合格人物外观图可复用，只控制身份与服饰。本次没有提供或读取外观图；两张所列参考均为计划职责，不预设任何平台的严格时序锁帧能力。

**主要验收点**

1. 人物始终站在同一对石砖上，真实身体、持物与脚下支撑不转移，结尾地标能回证原站点。
2. 画面依次经过真实脸庞、水面倒影、倒影内部抬仰、桥底阵面，核心过程连续可见；不是脸部一闪后直接换成桥底。
3. 倒像与实体的姿态、器物数量和左右成像关系对应；倒影没有变成可独立行动的人。
4. 缺角栏柱、桥拱石缝、水线在视点变化中可追踪；镜头路径走桥外及拱口空隙，不穿过实心石桥。
5. 圆阵始终固定在同一桥腹、阵面朝水，末段可看清桥底连接点与下方水面，足以区分“倒悬阵体”和普通颠倒画面。
