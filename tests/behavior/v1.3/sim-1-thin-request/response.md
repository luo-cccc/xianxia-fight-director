# 1. 设计卡

**角色目标**

- 甲（御剑）：带着那只封蜡竹筒，从林北沟口出林。不以杀乙为目标。
- 乙（符＋近战）：不让竹筒出林——能夺下就夺，夺不下就让它留在林里。

**有效规则（本场，可撤销）**

- R1 实体飞剑只有一柄；无剑气、无残影。剑脊冷光只在甲驱它时亮，断控即灭。
- R2 甲的御空靠脚下这柄剑。剑离身去攻，她就只有两条腿；无剑翻不出沟口的石坎以外的任何高处。
- R3 甲以视线与神识驱剑，剑能使的力不超过她本人能使的力；被实体卡死时要一段直路或用手才能解。
- R4 乙的符必须贴在竹节上才带得动整竿；**左手**夹符、贴符、掐诀，右手始终持刀。符共两张，用掉不补。
- R5 乙不御空。地面上乙短冲约每秒六米，甲低姿快走约每秒二点五米；但乙看不穿贴地那层雾。
- R6 不设境界表、不设倍率。强弱只由距离、视野、动作占用和剩余资源兑现。

**关键转折**（B06，全场 20.2–25.5 秒）：剑低回到甲手里的那一下被乙最后一张符的低束压死。甲用右掌的皮肉换回一只手和那只筒，弃剑；乙的符贴得太低，连自己的右脚踝一起缠了进去。铺垫：B02 的倒竹结封死宽道（剑只能低回），B05 乙左肩受竹（他的符只能贴到膝高）。

**所知与实际**

## 3.1 动作拍（时码均为成片时间）

- **B01｜0.0–8.5**　甲为抢在乙察觉前走完茬区，弃乘：她徒步北行，只放空剑沿宽道北飞，用冷光占住乙的注意。乙在石埂上以雾中那团冷光判位，左手两指抬至胸前待发。建立所知/实际。
- **B02｜8.5–11.0**　乙把预埋的那张符押在空剑上：宽道东缘四根成竹向符位交叉倒伏，缠结中心空无一人，只刮到剑身，把剑挑出宽道、向东北散开。甲伏在一丛幼竿后不动。结果：宽道封死（A1）、符一不可逆烧尽、甲的剑要绕约六十米才回得来。
- **B03｜11.0–14.5｜`breath`**　不出新攻击。符灰落、炭节起白烟被风带向东北、倒竹回弹停稳、缠结中心是空的；东侧叶层上一道新塌的浅痕和一根还在抖的折茬（A2）。乙读出这两件事，转身面西偏北，左手从袖中抽出最后一张符插在腰带前侧。甲仍不动。**识破发生在此。**
- **B04｜14.5–17.0｜`adaptation`（requires B02、B03）**　乙放弃封路，改夺筒：他从一点二米的石埂跳下，以约每秒六米横切十四米茬区，抢在甲与北沟口之间落定。甲起身北跑，被截下，转侧身把筒护到西侧，右手空。
- **B05｜17.0–20.2**　近身争筒。乙以刀背压住甲右臂外侧，左手扣上筒口，蜡面出现裂纹。甲左臂被筒占着、右手空，无法格挡：她拉弯一根幼竿后松手，回弹击中乙左肩。乙受这一下，不退，换成满握——他左臂此后抬不过肩。画外飞剑绕过石埂东侧折向南，冷光在竹梢上扫过一道。
- **B06｜20.2–25.5｜`pivotal`**　剑贴着茬区低路从西北回来（宽道已被 A1 封死，它只能走低路）。乙必须松一只手才能用符：他放开筒口，左手把符二按在膝高的幼竿节上掐诀——肩伤让他贴不到更高的节。十余根幼竿向符位内倒交叉（A3）：剑柄刚进甲右掌，剑身即被两根老茬与内倒幼竿压死，一根幼竿把她右掌背压在护手翘边上。甲抽手，虎口与掌心被翘边割裂，弃剑，冷光灭；同一动里她把筒从乙已松的左手上带走，筒口那圈裂蜡与一片薄竹皮留在他掌心。乙贴得太低的符把他自己的右脚踝也交叉缠住，两处幼竿节裂开漏水（A4）。
- **B07｜25.5–34.0**　甲把筒塞进衣襟，北走第一步踩上湿叶滑开（A4），不肯用右手撑地，以左肩着地，起身翻出一点五米的石坎。乙用刀背割开缠住脚踝的幼竿，北走两步即停：他左臂抬不过肩、右手握刀，翻那道石坎需要一只承重的手；符已用尽，封不住沟口；而被压住的剑就在脚边，拿走它她就永远飞不起来。他转回去，把刀背插进交叉的竹隙里别剑。

⑥ **21.5｜S05 终＝S06 起**　雾同⑤。甲在茬区距北沟口约七点三米，右膝跪地面西北，右掌已握住剑柄、掌背被一根内倒幼竿压在护手翘边上，虎口正在裂开，左臂仍抱筒。乙在甲正北约一米，右脚踝被两根交叉幼竿压住，上身北倾，右手持刀，左手刚离开筒口、掌心贴着一圈裂蜡与一片薄竹皮；左臂抬不过肩，符已用尽。实体飞剑横陈在两根老茬之间、绝对高零点三米，被十余根内倒幼竿交叉压住，剑脊冷光将灭。膝高那一节符位炭黑，两处幼竿节裂开漏水，近处叶层正在被打湿。宽道仍被倒竹封死。

⑦ **25.5｜S06 终＝S07 起**　雾下光转弱，西南风弱，竹梢偏东北。甲在茬区距北沟口约七点三米，起身面北，左臂抱筒，右掌虎口与掌心裂开、右手蜷着不受力，身上无其他伤。乙在甲正南约一米，右脚踝被两根交叉幼竿压住，面北，右手持刀，左臂垂着抬不过肩，掌心一圈裂蜡与一片薄竹皮，符已用尽。实体飞剑横陈在两根老茬之间、绝对高零点三米，被幼竿压住，冷光已灭。茬区两处幼竿节漏水，近处叶层湿；宽道被结顶约两米的倒竹封死，符位炭黑。

⑧ **34.0｜S07 终**　雾下光转弱，西南风弱。甲在北沟口外石坎顶（顶面绝对高一点五米）站定面北，成逆光剪影；封蜡竹筒已塞进衣襟、筒口那圈蜡缺失，右手蜷在胸前不受力，左肩有一片湿泥痕，手上无剑。乙在茬区距北沟口约五点五米，脚踝已被刀背割开的幼竿释放，蹲在被压住的剑旁面西，右手把刀背插进交叉的竹隙里，左臂垂着，掌心一圈裂蜡与一片薄竹皮，符已用尽。实体飞剑仍横陈在两根老茬之间、绝对高零点三米，冷光已灭。茬区叶层湿，宽道仍被倒竹封死。

风险 high｜保底：分两个可读瞬间——甲右掌从幼竿下抽出的近景（血、护手翘边），乙掌心摊开的裂蜡壳近景；两人分离的身体关系交给前后镜与画外竹响，起终态不变。

# 5. 精简视频执行稿（每段独立可用，时码为段内成片时间）

## G01｜段内 0.0–14.5

**本段规则**：实体飞剑只有一柄，无剑气无残影；剑脊冷光只在被驱动时亮。符必须贴在竹节上才带得动整竿，贴符与掐诀都用左手，右手始终持刀。贴地雾厚约一点五米，雾面以下看不清人，冷光在雾里散成亮团。主风西南向、弱，竹梢与雾偏东北。林地地面为零点，人物高度按脚底。
**资产锚点**：修士甲——墨青短衫、开襟过膝长袍、两指宽黑腰带、高束发黑绳、右前臂旧白疤。习武者乙——土褐粗布短袍下摆束入腰带、绑腿布、左袖内一排符袋、短发裹布带。窄身直剑——剑脊一道暗棱、护手两瓣朝前微翘。竹筒——两掌长一拳粗，两端各一圈深红封蜡。阔背短刀——刃长约一掌半、刀背厚约一指、素木柄。

**起态**：贴地雾厚约一点五米，西南弱风，竹梢与雾偏东北。甲在老竹茬区距北沟口约二十六米，面北低姿步行，头在雾面以下；左臂抱封蜡竹筒，右手空，无伤。乙在石埂顶面（绝对高一点二米）、甲东偏北约十一米，面西偏南站定；右手持阔背短刀，左手空。唯一实体飞剑在宽道上甲身后南面约四十五米，贴道面绝对高零点九米，剑尖朝北、以每秒六米北行，无人乘，剑脊冷光亮。符一已贴在宽道东缘一根成竹第三节、绝对高一点六米处；符二在乙左袖。宽道通畅，叶层未动，无痕迹。

**0.0–8.5**　无人乘的直剑沿宽道持续北飞，冷光在雾里移成一团亮斑。甲在东侧茬区雾面以下低姿北行约十米，末段伏到一丛幼竿后，双膝与左肘着地。乙在埂上随那团冷光转头判位，左手两指抬至胸前、诀未发。
镜头：侧向低机位跟冷光北行，停在能同时看到宽道与东侧茬区处，再横摇向东、下移到雾面找到甲。
光照：主光为东面低角天光穿竹隙的光柱；剑脊冷光作次光，照亮它经过的雾层与下段竹面，照不到甲；乙被天光从背后勾出轮廓，甲在暗部。
效果：剑过雾只划开一线、稍后合拢；道旁成竹梢不随剑下压。
声音：竹叶沙沙、远处竹节轻响、画外偏南的剑过雾低啸、甲脚下极轻的叶碎声。无对白。
保底：固定机位守宽道侧面，让冷光在景深里穿过一次；甲只用前景竹叶后一只抱筒的手与一截小臂交代，人与剑不同框。

**范围与依据**：全场 34 秒、七镜、三段的文字稿。依据只有你那一句话（两名修士、竹林、要好看）；世界规则、人物、目的、结局、时长、画风均由我新设并标为可撤销假设。未读取任何参考图、未生成任何媒体。

**已修**（交付前自己改掉的，列影响成立的几处）

1. 乙原设计为"左手夹符、右手持刀，同时扣住筒口"——一只左手不能同时持符与扣筒。改为符二插在腰带前侧，并把"**他必须松开筒口才用得上符**"变成转折的正面内容：筒因此是他主动松手交换出去的，不是打偏。
2. 乙原本在余波里"选择不追"——按规则这是替对手放弃行动。改为他贴得太低的符把他自己的右脚踝也缠住（肩伤迫使他只能贴膝高的节），他用刀背割竿花掉时间；之后不追的三条理由（抬不过肩的左臂、握刀占用的右手、用尽的符）在整段余波里一直成立，而且他转去拿更要紧的东西——她的剑。
3. 老茬高零点四至零点六米，而被压住的剑在绝对高零点三米：S05 原写"近地面侧向低机位"会被最近的一簇老茬挡住接点。改为机位落在两簇老茬之间的空隙、抬到约零点五至零点七米俯小角，接点在最近一簇茬顶之上可见；保底的接点特写同样从这个空隙进。
4. 痕迹 A1（倒竹结）原本只记在状态里。改成它决定剑的回收只能走茬区低路——这正是 B06 的膝高低束能压住它的前提；来源拍 11.0 秒结束，早于最早转折 20.2 秒。
