# 雪桥·25秒·二维动画《活人不过桥》

规格：成片 25.0 秒｜6 镜｜3 制作段｜7 张关键帧｜二维动画。全文时码均为**成片时间**。

---

## 一、设计卡

**角色目标**

- 沈荻（炼气期）：把昏迷的师姐送到南岸。判定为师姐的身体越过桥南端符钉、落在南岸雪地上。她自己过不过桥不在目标里——这一点她到桥心才想明白。
- 卫章（筑基期）：不让任何人**带活人过桥**。他守的是"带活人过桥"这个动作，不是桥上的人命。
- 师姐：全程昏迷，不做选择，只提供重量、体温和一口呼吸。

**有效规则（只列本场真正影响行动的）**

1. **镇桥阵读"生息"**。阵由卫章布在桥面冰层上，北端、桥心偏东、南端各一枚铁符钉。感应线一旦读到有生息的身体越过北钉或南钉，冰层就从脚底和衣摆向上攀咬，把人冻在桥面上。它不辨体温与心跳，**没有呼吸的身体，对它等同于一件货物**。
2. **阵心开关在卫章右脚下**。心钉需要持续承重才维持咬合；他一抬右脚，咬合即松。三钉认他的气息为阵主，不咬他。砸断两端钉只断该端感应，砸断心钉全阵失效——沈荻双手抱人、肩膀发麻、修为不足，砸不动。
3. **境界差的兑现方式**：卫章神识覆盖整座桥，背对也知道沈荻在哪；护体让沈荻的撞击只震开自己的肩，撞不动他；他能一边出手一边维持心钉承重。沈荻神识只有一两步，不会御剑御空，前半场双手被师姐占满。卫章职责只到"拦住"，不追杀、不越界，全场剑未出鞘。
4. **龟息诀**：炼气期可用的压息手法，一次按掌，压出几息长的无呼吸窗口，不需持续按压；对已经受伤的人用它有风险。沈荻会，只敢用一次。

**关键转折**

双脚被冰咬住、确认自己永远过不去之后，沈荻换掉了目标：不再自己背人过桥，而是把师姐从背上卸下、压掉她的呼吸让阵读不到她，再顺着冰面把她推过去。这一下把卫章困在他自己的阵里——抬脚去追，沈荻当场脱身，三步就能过桥，命令直接失败；不抬脚，就只能看着那具无息的身体滑过南钉。他的命令写的是"活人"，他神识读到的是"无息"。他留在钉上。

**铺垫**（转折之前已给足的线索）

朱线随卫章呼吸明暗，点出"阵"与"息"的关系；他全场右脚不离心钉，点出开关位置；沈荻每一次落点都在冰面刮出一道弧痕，"滑"是她从开场就在用的语言。

**终态**

师姐躺在南岸雪地，离南钉约一步半，呼吸正在回来，仍昏迷，身边无人。沈荻跪在桥心，膝以下冻进冰里，后颈被卫章提着——没过桥，也没赢。卫章右脚仍在心钉上，剑未出鞘，命令在字面上完整。冰面留下一道从桥心到南端的长弧痕。

**记忆画面**

沈荻双脚冻死在桥心，上身向南扑出、十指还张着；师姐沿冰面滑向东侧那段断掉的栏杆；卫章俯身扣住她的后领，右脚一寸没离那枚钉。

**招式签名**

- 沈荻：不用手（前半场手被占满），只用膝、肩、髋、背；顺着冰发力而不是对抗冰；每个落点留一道弧形刮痕。
- 卫章：剑不出鞘，连鞘当横杆用；右脚永不离钉，所有动作绕这个支点展开，扫踢只用左脚；只打对方的承重脚和抱人的臂，不伤人。

**创作假设**（可撤销，用户另有设定时以用户为准）

镇桥阵的三钉结构、认生息规则、阵心承重开关；龟息诀及其代价；境界差的上述兑现方式；卫章只执行字面命令、不追杀；师姐未命名，全场以"师姐"出现；桥的尺寸、东侧断栏、横风方向；两岸无第三方，25 秒内无援兵。

**已修（设计过程中发现并改掉的）**

1. 卫章原本用右脚扫踝 → 右脚正踩着阵心开关，一抬脚咬合就松、沈荻当场脱身。改为所有动作以右脚为支点、扫踢只用左脚，并把这个限制变成他的招式签名，最后又成为他两难的来源。
2. 心钉原本放在桥面西半侧 → 会挡住沈荻沿西侧的冲刺路线，也挡住师姐的滑行轨迹。改为心钉在**东半侧**、开放通道在西侧；横风（西→东）于是把滑行的身体推向卫章与断栏那一侧，抉择瞬间才成立。
