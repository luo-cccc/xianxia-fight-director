# sim-2-revision 笔记

## 实际走的传播链

规则/资产 → 动作 → 分镜 → 关键帧 → 执行稿，但真正的顺序不是这个。实际发生的是：

1. **先算慢镜值多少秒**。读完简报第一件事就是把 4.904 米 ÷ 8.2 米/秒 算出来 = 0.598 秒，于是知道那一镜从 4.0 秒塌到 0.8 秒，自己交出 3.2 秒。六秒里一半有了来源，剩下 2.8 秒才需要去别处找。
2. **再找哪里不能动**。呼吸拍钉在 13–15.5、段界钉在 15.5、交接帧钉在 15.5 —— 这三条合起来把 0–15.5 秒整段冻住了。全片 55% 的时长不可动，六秒只能从剩下的 45% 里出。
3. **规则/资产这一层其实没改**。本场规则一条没动，资产锚点一个字没动。改的是规则的**后果**：驻剑十二秒 ＋ 定高不能主动升降，这两条原本各自独立，我把它们乘起来当成了秦砚的逼迫条件。这一步是本次修改的全部支点，下面单独说。
4. **动作 → 分镜 → 帧 → 执行稿**这四层是顺着走的，没有返工。

### 晚才发现的三件事

**(一) 旧稿有一次没写的位移，我在写虚招拍时才撞上。** 旧稿 xf01_beat_seize 结束时杜彻在 (0.9,2.4)，xf01_beat_feint 结束时他在 (0,4)——相距 √(0.9²+1.6²)=1.836 米，中间没有任何一行字交代他怎么过去的。旧稿的虚招拍只写他"横棍封中线、重心后移"，没给米数。我在排新时码时需要他退到碎粒区才能打滑落膝，于是把这 1.836 米写成了 21–22.8 秒的后退（1.146 米/秒），顺手把一个旧漏洞补掉了。但这是**我为了自己的编舞需要补的，不是我发现它是漏洞才去补的**——如果新结局不需要他退到碎粒上，我很可能照抄旧稿、继续让他瞬移。这是本次最不体面的一处：审阅清单里"状态连续"那一行本该在我动笔前就查出它。

**(二) 出剑那一程的速度前后矛盾，我在最后一遍复算时才发现，而且没法修。** 按旧稿坐标与时刻独立重算：
- 6.5→8.2 秒：(−0.6,3)→(2,1.8)→槽外 x=2.3，约 2.68 米，1.58 米/秒（若松手算 7.0 秒则 2.23 米/秒）
- 8.2→9.5 秒：(2.3,1.8)→(2.3,3.5)，1.70 米 ÷ 1.3 秒 = **1.31 米/秒**
- 9.5→10 秒：(2.3,3.5)→(2.3,4.6)，1.10 米 ÷ 0.5 秒 = **2.20 米/秒**

同一柄剑、同一节点供能、同一条直线，中段慢到 1.31 又加速到 2.20，正文没给原因。这正是 review-and-repair 数值复算那一节的第一个例子（"脉冲一 1.49、脉冲二 2.24，无解释"）——v1.2 漏掉的错误在 v1.2 的稿子里又犯了一次，而我是在写审阅摘要时才查到。

**修不了，因为它在不变区内。** 它落在 6.5–13 秒，是用户没要求改的部分，而修它要动 xf01_shot_02 和 xf01_frame_02。更麻烦的是 8.2 秒这个数不是普通时刻，它是驻剑十二秒的起算锚点，而本次全部余量计算（20.2 秒、1.5 秒余量）都挂在它上面。所以我只能把它写成待核项，并给一个保住 8.2 秒的最省修法：松手改 6.7 秒、全程单一速度 1.77 米/秒（5.30 米 ÷ 2.99 秒），则 8.2 秒穿缺口不变、9.5 秒剑在 (2.3,4.08)（原写 3.5）、9.7 秒驻留（原写 10）。**代价是 9.5 秒那张关键帧的位置描述要改 0.58 米。** 我没有擅自改它。

**(三) 我把身体中线距离当成了手的距离，写完四处才回头改。** 接点 (0,2.4) 到秦砚 (−0.6,2.7) 是 √(0.6²+0.3²)=0.671 米，我在四个地方写成"离他的手还差 0.67 米"。错的：剑是柄朝前飞回来的，钩口咬在护手后方，剑柄从钩口朝他这侧伸出，所以 0.67 米是**身体中线到接点**，手到剑柄只剩两掌宽。这个错误不改也不会被算术抓到（0.671 这个数本身是对的），但它会让"他要上半步才能握住"变成假动作——真实原因不是够不到，是那只手当时是并指指向的姿势、不在握位上、体重也不在后面。四处已改，并把上半步的理由改写成"把体重放到拧转后面"。

**湿面扩散是我编的。** 旧稿只写"槽水持续漫出、向西南扩开"，没有速率。新结局需要它在 24.5 秒吃掉 x=0–2、y≈3.3–5.1，我就反推了一条减速曲线，再拿旧稿里两个已有的落点（22.8 秒"左脚踩湿面西缘"、24.5 秒"右膝落湿石"）回校——两个点都恰好落在边缘上，所以这条曲线至少与旧稿已写的两处落点不矛盾。但它仍然是假设，不是算出来的，已登记为可撤销假设。

**0.8 米那条缝是本次唯一真正"算出来"的剧情。** 杜彻单手 1.3 米 vs 双手 1.7 米，差 0.4 米；西栏在 x=−2.0；他跪在 x=0.1。于是干带剩 0.8 米而不是 0.4 米，而那 0.4 米的差额正好是 xf01_cost_wrap（握带撕断、左手无法定位）的直接后果。**"北路谁都没拿到"不是我判断的，是这个减法的结果**——他封不严，是因为他付过那笔代价。这是整次修改里我唯一满意的地方。

## 28 秒里变得难受或做不到的 v1.2 要求

**(1) 呼吸拍不可移 ＋ 禁止等比缩放 = 55% 的时长被冻住，六秒全压在 45% 上。** 15.5 秒之后原本有 18.5 秒，现在要塞进 12.5 秒，**那一段被砍掉 32%**。规则两条各自合理，合起来的后果是：你不能动前半场，所以后半场要承担全部压缩。skill 和两份参考都没提这个组合效应。如果用户再要求压到 24 秒，呼吸拍那 2.5 秒就必须进入讨论——15.5 秒的冻结区会超过总时长的三分之二。

**(2) 余波被压到 0.6 秒，这是真的损失。** 旧稿离场有 6 秒，秦砚走五米、绕开湿面、回头站定。新结局不需要走路，但"两人各自读一遍场面然后同时退开"这个决定需要被看见——我只给了 25.4–26.0 共 0.6 秒。秦砚要在这 0.6 秒里看完北面三处地形、看完对手的钩口覆盖、再看一眼自己手里的缺口剑。**0.6 秒看三样东西，这是在赌观众已经在前面认识了这三样东西。** 赌赢的条件是碎粒区（xf01_shot_01 就建立）、湿面（shot_05/07 一直在长）和缺口（frame_06 特写过）都已经出现过——确实都出现过，但"看一眼就懂"和"有时间懂"不是一回事。这是我被迫接受的最大妥协，比慢镜那件事更让我不放心。

**(3) 决胜接点的预备帧到接触帧只隔 0.8 秒。** 旧稿是 20 秒预备 / 22.5 秒接触，隔 2.5 秒（因为中间是慢镜）。现在 18.5 / 19.3，隔 0.8 秒。规则要求关键转折给预备、接触、结果三帧，但**没说预备帧和接触帧之间需要多少成片时间才读得出"预备"**。0.8 秒的预备帧在成片里基本是一闪——我靠的是预备帧里那三样东西（节点刚暗、二指指向、钩头已在线上）本身信息量够大，而不是靠它停留得久。如果生成出来观众读不到，这组三帧就只是三张图，不是一个因果。

**(4) G03 过载。** 段三只有 7 秒，里面装了三个镜头、虚招的完整三帧、段末单帧、节点熄灭、撬棍、打滑、落膝、换单手、双方同时退开。段二反而只有 5.5 秒装两镜。**段长 15.5/5.5/7.0 这个分布很丑**，但段界只能挑稳定瞬间，而 15.5（呼吸拍末）和 21.0（剑刚归手、双方停住）是全片仅有的两个真正站定的时刻。我选了可复现性，牺牲了段长均衡。

**(5) 没有丢任何一项必须活下来的东西。** 四笔代价、呼吸拍、两张交接帧、两组三帧、光照弧，全在。但"全在"有一处是靠重新解释达成的：xf01_frame_07 从 25 秒移到 21.0 秒，**旧稿那张交接帧本来就停在"正在抬腕"这个半动作上，是 continuity-and-timing 明确要求避开的**。我移动它的理由是新时码需要，但顺带修了旧稿一个违规。这算修复，不算保留。

## 规则不清、自相矛盾或没说的地方

**(甲) 拆镜时 ID 跟内容走还是跟时间走？规则没说，而这次必须选。** continuity-and-timing 说"若需在镜头中部切段，先拆成两个连续镜头，再更新拍引用、状态、关键帧与声音"；review-and-repair 说"保留无关 ID，不另造复杂边界编号"。两条都没回答：旧 shot_06（虚招）被我拆成两镜，旧 shot_07（离场）内容被新结局替换，结果是新 shot_07 的窗口和内容**与旧 shot_07 完全无关**，离场的位置挪到了新建的 shot_08。

我选了按时间顺序编号，因为时码连续性是结构检查的硬要求，而"shot_07 还叫 shot_07 但讲的是另一件事"只是读起来别扭。但这意味着**任何引用旧 shot_07 的外部资料（已生成的片段、排期表、素材命名）现在都指向错误的内容**。反过来如果保内容、把新镜插成 shot_08 塞在 06 和 07 中间，ID 顺序就不再单调，排序和导出都会出问题。**两条路都有代价，规则对此完全沉默。这是本次最大的规则缺口。**

**(乙) 取消慢镜后，接点有没有最低可读时长？没有任何规定。** 规则对慢镜写得很细（成片窗口、世界阶段、各方同步三件事都要写清），对**反向操作**一字未提。取消慢镜是把一个 4 秒的呈现压回 0.6 秒世界时长，决胜接触从此只有 0.8 秒飞行 ＋ 0.4 秒静止。规则同时要求关键转折必须有预备/接触/结果三帧——但如果整个接点只有 1.2 秒，三帧之间的间隔会短到帧与帧互相挤压。**规则要求三帧，又不保证三帧有地方站。** 我的处理是给接触后留 0.4 秒实打实的反应静止（不是慢镜，是人的反应时间），让接触帧有一个真实的停顿可以钉。这是我自己想的办法，规则里没有依据。

**(丙) 压时长时没有取舍优先级。** review-and-repair 的"时长不足"条写的是"删重复拍、简化支线和能力，保留必要准备、移动、反应与对白"。但这一稿**没有重复拍，没有支线，能力只有三枚节点和一根棍**。该删的东西一样都没有，六秒却必须出来。真正占时长的全是强制项：四笔代价要有来源和后果、呼吸拍 2.5 秒、两组三帧、段界要停在稳定瞬间、光照弧要逐镜变化。**强制项本身就是开销，而规则假设开销在可删的部分里。** 结果我只能从奇观（慢镜 3.2 秒）和余波（离场 3.4 秒）里拿——这两样恰好是规则最不强制的两样，于是"压时长"在实践中等于"砍掉所有不强制的东西"。28 秒还撑得住，24 秒就撑不住了。

**(丁) 重排时码会静默改变资源余量，没有任何规则要求回查。** continuity-and-timing 把起算事件讲得很透（"自剑穿出槽沿缺口的 8.2 秒起供能十二秒，至 20.2 秒"），也讲清慢镜不消耗预算。但它没说：**当你把一个消耗动作往前挪，余量会自己变。** 我把回召从 18.5 挪到 18.7（因为设钩窗口要 3.2 秒），余量就从 1.7 秒变成 1.5 秒，没有任何检查项会提醒我。抓到它的是数值复算那条"凡写算准、刚好的地方复算余量"。1.5 秒按险过写了，但这纯属我自己多走了一步。

**(戊) "至少一个呼吸拍"没说能不能有第二个。** 我在 25.4–26.0 放了 0.6 秒双方都不动、只读场面的窗口。它符合呼吸拍的定义（不发起新攻击、只让观众看清已改变的状态、不与关键转折重叠），但我**没有给它登记 breath 标记**，因为规则只说"至少一个"，没说多了算不算、要不要标。标了怕被当成两个呼吸拍互相稀释，不标又让这 0.6 秒在结构上无名无分。规则对此沉默。

**(己) 动作拍 ID 的语义和内容脱钩，和 (甲) 是同一个病。** xf01_beat_exit 现在没有人 exit——它是双方同时退开、谁都没走成。我按"保留无关 ID"留下了这个名字，于是 ID 在骗读者。规则要求保 ID，但 ID 带语义时，保 ID 就等于保一个错的标签。

**(庚) 双方皆败的结局，代价规则没有适配。** 规则写"给赢的一方也记代价"——它假设有一个赢的一方。新结局没有赢家：秦砚保住剑和身体但没过北闸，杜彻没夺到剑还跪下了。两边都付了不可逆支出，要求是超额满足的，但**"误判是否真的损失了东西"这类检查在没有赢家时怎么判，规则没讲**。我的做法是让四笔代价各自指向新结局里一个具体的、还在发生的限制（最关键的是那 0.4 米覆盖差），用代价本身替代胜负来收束这一场。这个做法成不成立由用户判断，规则给不了背书。

## 没能满足的

**(1) 槽外那四秒剑光找不回来。** 旧稿 xf01_shot_04 的"回召剑光沿槽外南下，经过时先照亮槽沿湿石并在地面反出一道移动青痕，这道反光先打到杜彻的下颌"——一股持续光束照亮它经过的表面与近处的脸，这正是 skill 里光照那一段点名要求的东西，而它是全片最好的一个镜头。0.6 秒装不下它。我用两样东西替代：开镜前 0.3 秒让钩口剪影背后的青光先亮（光比剑先到），以及 shot_04 整段让"双方都没有光、主光归场景"——**都比不上原来那个镜头。这是降级，不是等价替换。**

**(2) 飞行中的微调没了，我把它说成了优点。** 旧稿杜彻在慢镜里微调钩口角度。0.6 秒里他来不及动，于是我写成"不动比微调更能证明预谋"。这句话我自己信，但我也清楚**它是先有约束后有理由**——如果慢镜还在，我不会主动把微调改成静止。读者有权把它当成事后合理化。
