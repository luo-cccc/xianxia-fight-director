# v2.0 单臂行为试用：方法与边界

## 为什么做

v1.5/v2.0 之前的行为证据停在 v1.3；v2.0 又移除了 1.1–1.3 兼容。本试用用 **v2.0 当前规则**重跑同一 25 秒雪桥请求，验证三件事：

1. 当前入口与参考能否产出完整的 1.4 工作存档；
2. 窗口规划能否按剧本关联定界，而不是按平台时长切；
3. `validate` / `export` 能否接受并导出 1.4 三窗工程。

## 设置

| 项 | 内容 |
| --- | --- |
| 规则版本 | v2.0，工作 JSON 1.4；只接受 1.4 |
| 请求 | 与 v1.3 双臂对照相同的 25 秒雪桥请求，见 [request.md](request.md) |
| 交付 | JSON 1.4 工作存档 + `bundle/` 七文件 + 本说明 |
| 对照 | 与 `../v1.3/arm-a/response.md` 只作定性对照；**本次不是盲测，也不是双盲对照** |
| 媒体 | 未生成、未查看、未听辨任何图像或视频 |

## 判断顺序

1. 先读剧本：目标是“背人过桥”，不是击败守桥人；沈荻炼气对筑基，正面不能赢。
2. 标关联簇：负人与绳栏承力（S1–S2）、斩锚柱到滑过（S3–S4）、抛人跳岸到保桥（S6–S7）。
3. 标切点：9 秒卫章转身、19 秒呼吸拍末为 A 级；4、17、22 秒为 B 级；滑过中段不设窗口边界。
4. 定窗口：0–9 / 9–19 / 19–25。平台未声明，因此不写上限；判断记录给出 10 秒与 6 秒阶梯。
5. 写接缝包：9 秒带左前臂伤、绳股裂口、薄冰与卫章的误判；19 秒带五项不可逆代价与四处痕迹。
6. 跑校验与导出，逐项人工复核。

## 证据范围

- `project.json` 通过 1.4 结构校验；`bundle/` 由当前 `export` 生成，七文件齐全。
- 结构通过不等于编舞成立；本试用仍在 `semantic_status: needs_review`。
- 单臂重跑不能证明 v2.0 规则优于 v1.3；它只证明当前规则与工具能产出并导出一套 1.4 三窗工程。
- 未实测平台、生成端、音频、引风符遮声或枪尖楔石的可执行性。
