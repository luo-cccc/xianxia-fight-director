## 判断记录

| 项 | 判断 |
| --- | --- |
| 目标 | 沈荻要背人过桥；卫章要拦人并保桥。两者冲突，不靠击杀解决。 |
| 对手能动性 | 卫章先刺前臂；看见沈荻抓绳后改斩北锚柱；枪尖楔石后选择保桥不追。 |
| 不可逆代价 | 沈荻左前臂、引风符、师姐左踝；卫章枪头、北锚柱。分属两方。 |
| 呼吸拍 | 17–19 秒：两人各停一端，枪仍楔石，绳断，无人再出手。 |
| 转折 | 9–17 秒：斩锚柱→放绳→引风→滑过→枪楔石；预备 11、接触 14.5、结果 16.5。 |
| 痕迹 | 薄冰（B1）、绳股裂口（B2）、锚柱裂（B3）、裂石板（B3）；最早痕迹早于转折。 |
| 所知/实际 | 卫章以为沈荻要靠绳；实际沈荻已放绳借冰滑过；线索是手指离绳。 |
| 窗口 | 0–9 / 9–19 / 19–25；9 与 19 为 A 级切点；平台未声明，不写上限。 |
| 降级 | W2 标 high；17 秒 B 级切点把 9–19 拆成 8+2；6 秒能力时提示改设计/更细拆。 |

## 结构检查

- 25 秒主镜头轴连续覆盖；7 镜、3 段、3 窗；段首尾与首末镜状态逐字一致。
- 相邻镜外层与 execution 起终态逐字一致。
- B3 为 pivotal+adaptation，三帧 11 / 14.5 / 16.5 严格递增；B4 为 breath，不与转折重叠。
- 9 秒与 19 秒各有归属前段末镜的 handoff 帧；窗口入口/出口帧对齐。
- 代价 5 项全部不可逆，归属沈荻与卫章两方；痕迹 4 项，最早在 B1。
- 窗口：W1 0–9、W2 9–19、W3 19–25；W2 高风险，17 秒为降级切点；W2/W3 接缝包带代价、痕迹与所知。
- 05 不含内部 ID；窗口状态、接缝包与窗口保底不含时码。

## 与 v1.3 的差别

- v1.3 甲臂是自然语言六件套；本稿是 JSON 1.4 + 导出，窗口规划成为显式对象。
- 本稿把“卫章改招”“符与冰面位移”“保桥不追”写成可查的节拍、代价与接缝包，而不是只写在分镜句子里。
- 本稿没有做双盲对照；不能据此声称 v2.0 产出优于 v1.3。
