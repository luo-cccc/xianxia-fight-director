## 读法

- 这些记录证明“当时读到的规则产生了什么”，不证明当前 v2.0 仍会这样产出。
- `v1.3/skill-manifest.json` 的 SHA-256 是 v1.3 试用开始时冻结的。之后规则多次修订：v1.5 新增 `references/window-planning.md`，v2.0 移除旧版本兼容并同步文档与测试。`python tests/behavior/v1.3/freeze.py --check` 会报大量漂移，属预期。**不要重新冻结**——重新冻结会抹掉“规则在试用之后改过”这件事。
- 历史记录里的“三段”“八份参考”“1.3”“JSON 1.3”等是当时结构，不是当前结构。当前示例为三窗，参考为九篇（含 `window-planning.md`），工作 JSON 为 1.4，只接受 1.4。
- 当前能重复的是结构检查与示例导出：`python -X utf8 -B -m unittest discover -s tests` 与 `python scripts/combat_plan.py validate examples/*.json`。结构通过仍不代表语义或成片通过。
