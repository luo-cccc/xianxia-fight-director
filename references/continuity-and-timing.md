# 连续性与时间：成片时间与世界动作进程

本页的完整覆盖、呼吸拍和战斗存档规则适用于完整战斗。单项非战斗场面按用户要求给自然语言窗口，不补造对手、变招或双方代价；同一连续动作的身份、物品和状态仍须承接。

## 统一成片时码

所有 JSON 数字时间与自然语言时码都以**成片时间**计秒。全场时码是从成片起点累计的时间；段内时码只是同一成片时轴减去段起点，不是另一条世界时间轴。小数精度用于文本定位，不保证生成器逐帧执行。

| 层级 | 描述 | 成片时间关系 |
| --- | --- | --- |
| 动作拍 B | 行动、回应、结果与因果 | 可并行、可跨镜，标其呈现窗口 |
| 镜头 S | 主剪辑当前展示的事件窗口 | 从 0 连续覆盖总时长，不重叠、不留空档 |
| 制作段 G | 独立制作的整镜集合 | 顺序分配所有镜头，每镜恰属一段 |
| 关键帧 K | 指定镜头的静态瞬间 | 钉一个成片时刻，另可标段内换算值 |
| 镜内登记项 | 光照来源与归属、生成风险与保底构图 | 随镜登记、随窗口变化，不另占时轴 |

镜头数不等于攻击次数。一个动作可跨镜，一镜可看多个动作；制作段也不是新一轮战斗，段首不能重演已发生的起手或命中。

## 慢镜与非线性呈现

慢镜写清三件事：**成片窗口、对应世界动作阶段、同窗各方同步进度**。不简单宣称“世界时间等于成片时间”，也不在没有映射依据时把呈现时长当成攻击真实耗时。

> 成片 8.0–10.0 秒为慢镜：呈现剑尖从护罩前缘进入接触、罩面刚开始凹陷的阶段。甲双手仍在压剑；乙只来得及转肩，左脚尚未落地；画外飞剑同阶段仍在回弧，没有在特写期间完成回手与再发射。成片 10.0 秒后接凹陷扩大与脚掌落地，恢复正常速度。

快慢变化必须保持相同世界进程：不能给被特写者慢镜，却让同一物理场中的对手按正常速度完成额外连招。主观加速、时间术法等若属于剧情规则，要与剪辑变速分开说明。

当前 JSON 1.3 延续 1.2、1.1 的成片时间语义，没有精确双时轴、重放与插叙映射。若用户需要，采用自然语言明确呈现顺序、事件顺序和同步关系，或提示需扩展契约；不往契约增塞世界秒数、重放标记等未定义字段，不把重放当第二次伤害。通常线性方案无需构造精确世界秒数表。

## 动作拍、依赖与观察窗口

每拍的 `start/end` 是全场成片窗口。例如 B01 为甲在成片 0.0–3.0 秒压住守卫，B02 为乙在成片 1.0–4.0 秒拔阵钉。B02 可在甲已引走视线时开始，不必等 B01 完成；部分进展触发写在行动条件里。

只有“前拍完成才允许后拍开始”才登记完成依赖。依赖不能自引、成环或引用未来完成事件。只在确需表示独立结果时拆拍，不为每个小动作建依赖链。

## 资源预算的时轴与起算事件

持续时间有限的资源（驻剑供能、符的延时、护罩维持、油室、灵力窗口）同样按**成片时间**计，和其他数字一个时轴；但“能撑多久”必须钉在一个**具体可见的起算事件**上，而不是只写一个时长。“供能最多十二秒”这句话单独成立不了：从离手算、从穿过缺口算、还是从停稳算，差出来的秒数会直接改变后面能不能来得及。

写法是把事件和时刻一起给出：“自剑穿出槽沿缺口的 8.2 秒起供能十二秒，至 20.2 秒”。这样读者能独立重算余量，审阅也能查出前后矛盾。只写“十二秒”而起算点有两种读法时，按最不利的一种重排动作，或者直接改写规则把起算点定死。

预算窗口跨慢镜时尤其要当心：慢镜放大的是呈现，不是资源消耗。一段成片四秒、世界动作仅 0.6 秒的回召，吃掉的预算是 0.6 秒那一份，不是四秒；但预算本身仍以成片时码登记它的起止时刻，因为全场数字都在这条时轴上。两者在同一段里同时出现时，分别写清：预算起算事件与成片时刻、该窗口对应的世界动作阶段。

引用某拍的镜头窗口并集覆盖该拍；仅碰到切点不算观察。画外行动可用声音、影子、反应或空间关系表达，但要说明主体和证据。导演稿保留完整跨镜 beat，并标本镜当前窗口；执行稿只保留窗口内进程。

## 镜头与共享世界状态

导演镜头记录示例：

> S03｜全场成片 4.0–6.5 秒｜关联 B02、B03｜可见资产｜世界起态｜本窗口行动、回应与结果｜景别/机位/运镜｜特效与声音｜世界终态

第一镜从 0 开始，末镜止于总时长；相邻镜的终止与起始时刻相等。镜头数量随空间和动作可读性调整。

镜长按当前窗口的信息量分配，接点可短、余波可长，避免机械等分。节奏属于语义审阅，结构检查只验证时间与引用关系。

全场至少要有一个呼吸拍（`breath`）：不发起新攻击、只让观众看清已发生状态的短窗口，既不兼任关键转折，也不与任何关键转折窗口重叠。对比与蓄势的方法见 [spectacle-and-style.md](spectacle-and-style.md)。

**每一对相邻镜的前镜终态与后镜起态逐字一致**，不只检查制作段边界。复用一份具体世界状态文本，不另外堆边界 ID。机位、景别、画面左右和构图放 `camera`，不要混入世界状态；反打可以改变构图，不能交换战场东西位置。

每镜另登记两项：`light` 写本镜主光来源、属于谁的能力或环境、谁被压成暗部，全场各镜不得完全相同，战局易手处改光源或改归属；`risk` 判断本镜是否承担不可替代的关键证据，标高的镜附一个更省的 `fallback` 构图，不估算无依据的成功率。精简执行稿的 `execution` 同样带 `light`，与导演稿同镜一致。取值与可查后果见 [delivery-contract.md](delivery-contract.md)，此处不复列字段。

按相关性保留：

- **人**：地标位置、高度、朝向、支撑面、重心与动势、可用肢体、伤势与失能。脚下、手上或飞盘提供的支撑按当前动作写，不默认每个角色始终站稳。
- **物**：持物手、归属、实体飞剑位置/朝向/动向、符箓消耗。
- **术**：维持者、覆盖、在途攻击、分身和法相状态。
- **场与限制**：破坏、节点、介质、退路，以及影响下一动作的资源、感知和专注。

无关项不机械填表；独立执行所需内容不可因精简丢失。“左肩撞柱后仍向北踉跄”比“自然衔接”可用。回剑、拾物、换手、移动和恢复站姿都要有过程；支撑脚正在滑开时，后镜不能未经重新落脚就完成重击。

世界高度沿用场景资产的零点和脚底/盘面口径，画面上下不改写绝对高度；相对高差写明比较对象。机位只投影这些已成立的空间状态，不能靠低仰角补出实际不存在的高度、距离或支点。

## 整镜分段与时间换算

按独立任务和入口已核实的限制选段界。未核实平台时不设通用秒数上限；可先交通用段稿及待核项。若需在镜头中部切段，先拆成两个连续镜头，再更新拍引用、状态、关键帧与声音。

段界还是编舞决定，且有结构后果：交接时刻要有一张可独立复现的 `handoff` 静帧，它归属前段末镜，不归后段首镜；前段末帧常被当作后段首帧的生成条件。因此按姿态可读性挑段界：

- **优先**：双脚落定、接点压实不动、持物与朝向明确的短暂稳定瞬间，呼吸拍尤其合适。
- **避开**：姿态、接点或残速尚不明确的半动作瞬间。
- **动作确实跨界时**：按上条拆镜，把段界移到拆出前镜的收势处，再同步拍引用、状态与交接帧。

帧的写法见 [assets-and-keyframes.md](assets-and-keyframes.md)。

导演稿保留全场区间、段长、镜头归属和换算：

> G02 全场成片 6.0–10.0 秒，段内 0.0–4.0 秒；全场 t = 段内 t + 6.0。S04 全场 6.0–8.5 / 段内 0.0–2.5，S05 全场 8.5–10.0 / 段内 2.5–4.0。

复制用执行稿只显示段内成片时码。JSON 的 `shots.execution.cues` 仍存全场成片数字 `start/end`，在所属镜内按序连续、无重叠地完整覆盖该镜；导出时统一减去段起点。`text` 及其余 execution 文字字段不写数字秒码，避免与可换算数值重复或冲突。需要描述快慢时写动作阶段，由 cue 数值定位窗口。

JSON 1.3 的主要效果阶段也用这条成片时轴，可跨镜、可并行。阶段起止落在相关镜头内部时与该镜 cue 边界对齐，正常切点不创建零时长 cue；瞬间接触由关键帧定位。阶段只组织当前进程，具体画面由作者写进对应 `execution` 窗口，不从效果摘要自动生成，也不强制按固定蓄力、爆发、消散顺序编排。精确数字仍是计划窗口，不承诺视频模型逐帧执行。

## 独立起终态与执行简版

段起态等于首镜起态，段终态等于末镜终态；相邻段共享同一世界状态，逐字一致。段界修改同步前镜终态、后镜起态、两个段和那张交接帧。

执行版可以删工程解释，不能删在途攻击、持续术法、伤损、持物和动势。若另写精简状态，执行版内部每对相邻镜也必须逐字共享；段首尾同步对应首末镜，含义与导演版一致。直接复用一份必要且完整的世界状态通常最省事。

持续特效跨镜继续原阶段，不能借切镜重新蓄力、恢复损坏或重复命中。特效转场描述画面出入条件，不自动允许人物瞬移、换场或时间跳跃；变身保留哪些身份、支撑、持物和伤损，按用户规则明确。用户要求连续过程时，选段界和保底均保留这一过程，不用稳定静图或遮挡替代。

> 共享状态例：东门内侧，甲距门两步、离地半身高，面北向后下坠；右手持短刀、左手抱药匣，左肩受伤。乙在门北侧地面面南，右手空置；唯一实体飞剑在甲右后方一臂处，剑尖朝西且仍向西飞行。门槛水线带电，东阵钉已断，西阵钉仍禁飞，甲尚无安全落脚点。

该状态可供不同构图的两镜共享。先查“起态可用条件 → 当前动作与回应 → 终态是否可达”，再设计呈现它的机位。逐字相同只能防登记漂移，还要确认前镜真能抵达、后镜真能发动；不能用共享文字掩盖瞬移、凭空换手或重心自动复位。

## 检查顺序

先查因果与同步，再查成片覆盖、相邻镜共享状态、整镜分段、cue 换算及关键帧归属；接着查段界交接帧、转折三帧、光照和累积痕迹，最后确认镜长按动作信息量分配。

修改时长先重排可执行窗口，不能只等比缩放数字；改段界先确认新交接瞬间是否稳定可复现，再同步交接帧与前后两镜状态。静帧规则见 [assets-and-keyframes.md](assets-and-keyframes.md)，证据界限见 [review-and-repair.md](review-and-repair.md)。
