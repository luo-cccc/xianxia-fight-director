# 战斗设计：让选择产生结果

本页用于完整战斗与战斗局部改稿。用户只要出场、仪式、治疗、构造或一个特效镜头时，按其变化目标直接交付，不强加对手变招、呼吸拍与双方代价；应用设计见 [effects-applications.md](effects-applications.md)。完整战斗 JSON 1.3 继续沿用本页编舞要求。

## 先写足够用的设计卡

设计卡保留六类必要信息：**角色目标、有效规则、关键转折、代价账目、终态、创作假设**。目标要能检验，如“拿到阵心并从北门撤出”“拖住持匣者直到封门”。杀死对手不是默认目标；保护、试探、夺物、延时和追逃会产生不同攻防。

战场布局归场景资产，外观归角色资产，逐拍行动归分镜。设计卡保留会改变本场选择的信息，不重复建立整套百科；复杂群战或大规模细案按实际需要展开。

代价账目记归属、支出物、来源、是否不可逆及后续动作限制，对应 JSON 的 `cost`。完整战斗至少两个主体付出代价，其中至少一项不可逆，优势方也要有条目。

分开人物所知、误判和观众线索。`design.goals` 只写角色任务；确有必要的导演观看任务放可选 `design.viewing_tasks`，不混入角色动机，也不带入精简执行稿。本场出现幻术、残影、虚招或其他误判时，设计卡写出所知与实际两栏，对应可选 `knowledge`：谁在判断、他信什么、真实是什么、哪一拍建立、观众可回溯的线索是什么、哪一拍识破。判断与真实不得逐字相同，识破不早于建立。

## 用条件建立优势

仅分析本场真正影响行动的维度，不逐项填表：

| 维度 | 具体问题 |
| --- | --- |
| 距离与位置 | 谁能有效威胁？接近、退路和空域受什么限制？ |
| 信息 | 谁看见实体、节点或施术源？遮挡改变了谁的判断？ |
| 时间 | 谁需要准备、维持或回收？谁只需拖延？ |
| 资源与承受 | 哪次爆发不可重复？伤势、护体具体限制什么？ |
| 牵制 | 谁要保护同伴、目标物或阵眼，不能自由选位？ |

境界差通过本作品已有的感知、距离、破防或持续能力兑现，不自创“高一境必胜”或倍率。用户已有绝对压制规则时认真落实。

## 从处境选择具体动作

动作不明确时，先看人物要夺物、护人、封路还是脱离，再结合当前距离、可用的手与身体支撑、器物能走的路径和对手可能回应筛选。抱匣者左臂被占用、后脚抵阶时，可以右手短剑贴开来刃后侧移；不能只因招式好看，就让他同时双手结印或无支点地转身发力。是否成功仍由对手选择、双方条件和实际接点决定。

需要特效时先确定它承担攻击、防御、控场、探测或救援等什么用途，再选择形态、传播和反馈；同一用途可以有多种类型，同一类型也可改变用途。不要为展示库中类型而增添无关招式，视觉机制选择见 [effects-library.md](effects-library.md)。

把招式名落成可见行为，如“回燕”写成“剑沿外侧低弧回收，剑脊拨开追来的枪尖，持剑者向柱侧让位”；名称可以保留，不能替代路径、回应和结果。动作资料检索是可选补充，只使用实际读到的内容，不要求联网或外部资料库。借用动作时重新核对本场器形、持物、距离和支撑，不照搬原素材的命中结果，也不另建庞大招式词典。

## 以状态变化组织少量动作拍

动作拍是因果单位，不是逐秒记录或每一拳的编号。普通短场先用少量能贯穿开场到终态的拍，只有新信息、关键反制或复杂并行确有必要时再拆；不预设拍数，不堆几十个 beat 与边界 ID。

推荐导演记录：

> B01｜成片 0.0–3.0 秒｜甲为夺北出口，贴柱逼近；乙横剑守住柱墙间隙，甲被迫停在柱后，却看清乙右腕旧伤。条件：出口可见，乙持剑在位。

每拍交代实际行动、对手实际回应和状态变化。只在关键选择有歧义时补一句理由，例如“后退会让出药匣，因此格挡”；无需每拍穷举合理选项、替代代价和决策树。分析时考虑选择，正文只留下读者理解所需的证据。对手不行动时，交代遮挡、职责、迟觉、动作占用或主动等待的原因。

没有命中也可推进：逼出位置、暴露施术源、消耗符箓、延迟回收、争取视野都有效。删掉不改变状态的重复拍，不为“有结果”安排双方轮流受伤。

## 攻防由条件推导

检查“准备/征兆 → 到达路径 → 察觉与回应 → 接触或避让 → 状态变化”。阶段允许重叠，不要求每次拆五拍或五镜。

- **发动**：手、视线、媒介、站位或专注是否可用？
- **到达**：距离、遮挡、速度和转向是否允许？
- **生效**：防御针对实体、能量、感知还是空间？
- **回应**：当前反应符合所知信息、职责和可用窗口吗？
- **留存**：器物在哪、哪只手空出、伤势限制什么、哪条路开放？

招式名标识能力，不能代替过程。“神通爆发击败敌人”需要施术源、范围、效果和对手失去选择的原因。设计角色招式签名及高燃画面的正面方法见 [spectacle-and-style.md](spectacle-and-style.md)。

## 对手能动性

对手持续推进自己的任务，并至少一次依据已察觉的信息改变打法，对应 `adaptation` 标记；`requires` 指向被回应的前拍。其可用能力应按任务与信息发挥，主角脱险须有具体原因。

- 可用的理由：岩体挡住锁定线、介质被切断、对手改去抢更要紧的目标、同伴替他挨了这一下、他付出了不愿付的代价。
- 不可用的理由：对手选择不出手、忽然迟钝、已登记的能力无故不用。
- 对手确实不行动时，原因（遮挡、职责、迟觉、动作占用）要在它生效的整段时间里都成立，不只在他该失手的那一拍成立。

## 转折与终态

转折改变优势结构，如“飞剑被阵纹牵住，远程优势转成回收负担”。此前提供阵纹牵引、剑路偏转或试探等足够线索，避免临末增加免疫或隐藏分身。

反制可改变介质、切断指令、遮蔽感知、逼迫守护目标、拆节点或借地形，不必永远输出更大。跨境成功依用户规则和具体条件成立；不能正面取胜时可达成逃脱、取物等局部目标。

终态兑现开场任务，保留人和物归属、可行动性、持续阵法、损坏与追兵位置。不为收尾重置伤损和资源。

## 不可逆代价

全场代价分属至少两个主体，优势方也付；可逆支出不能构成全部账目，至少一项支出收不回来。误判要兑现为不可逆损失。

每项支出指名它此后限制哪个具体动作：缺口的剑脊不能再硬磕枪身、烧尽的符位此后无法延时封路、伤腕握不住回收的剑。写不出被限制的动作，这项支出就还没发生。

终态按归属逐项保留不可逆项，之后每处引用都当它仍在起作用。`cost` 的结构校验只看有无不可逆项、归属是否多于一个；支出是否真的约束了后文，属语义审阅。

## 并行与节奏

同一成片窗口内，各方行动同步登记，例如甲缠斗时乙拆阵。镜头重点只呈现当前必要因果，画外支线仍有状态、结果和证据。慢镜延展的是呈现，不能让没被特写的人凭空等待或多做一轮动作；具体方法见 [continuity-and-timing.md](continuity-and-timing.md)。

新规则或空间变化给识别时间，已建立的连击可压缩。压力、停顿、爆发、撤离随处境安排，不固定反杀位置、回合数或慢镜比例。若时长不够，先删重复攻击、简化能力与支线，再调整节奏，保留必要准备、飞行、反应和对白时间。

节奏靠对比成立，全场至少留一个呼吸拍：不出新攻击，只让观众看清已经变了的状态——谁在流血、哪只手空了、符位烧到哪里。它对应 `breath` 标记，不兼任 `pivotal`，也不与任何 `pivotal` 窗口重叠，否则停顿被爆发吃掉。呼吸拍姿态短暂稳定、轮廓可读，通常是最好的段界。

镜长和镜内细拍按信息量分配，避免机械等分：蓄力给足威胁辨认时间，接触可短，余波留够读取结果的窗口。节奏属语义自检，不由结构校验判断。

## 紧凑自检

- 去掉招式名后，还能理解谁改变了什么吗？
- 对手的行为符合目标、所知信息和动作占用吗？他自己的计划是什么，哪一拍据已察觉的信息变了打法？
- 谁不可逆地付出了什么，它限制了后面哪个动作，终态里还在吗？
- 呼吸拍在第几秒，它让观众看清了什么？镜长是按动作需要分的，还是按总时长等分的？
- 终态能由此前规则、位置和铺垫推导吗？
- 当前动作与伤势、持物、持续施术是否冲突？
- 最小完整六件套是否覆盖全场，扩写是否真的增添信息？
