# 审阅与修复：依据证据完成可用交付

## 一次轻量审阅，先修上游问题

完整交付前做一次有依据的文字审阅。局部修改只检查受影响链和交接点，不重新开启全量审批或多轮模型测试。先修会使结局无依据、时空不可能或素材来源失实的问题，再改善表达。

| 检查面 | 具体检查 | 最小修复 |
| --- | --- | --- |
| 覆盖与篇幅 | 全场六件套是否先齐，是否前半过度展开而后半缺失 | 压缩重复说明，先完整覆盖，不留 CONTINUE 等待 |
| 目标与因果 | 行动服务人物任务，反制有信息来源 | 调整选择、补已有条件线索，撤无依据全知 |
| 机制与条件 | 发动、路径、生效、回应符合有效规则 | 改距离、介质、动作占用或代价，不临时加免疫 |
| 状态连续 | 每对相邻镜起终态逐字共享，且前镜可达、后镜有支点、可用肢体与路径 | 补移动、回收、换手或落脚过程，同步导演版和执行版 |
| 时间与同步 | 成片窗口连续，慢镜说明世界阶段与各方同步 | 重排窗口，不把成片秒数当世界耗时，不凭空多行动 |
| 高燃与可读性 | 招式辨识、压力与爆发是否具体，接点和尺度可见 | 改动作、机位或层次，用余波证明结果，不堆形容词 |
| 资产与参考 | 身份锚点未锁死持物/姿态/伤损；只使用本窗口状态；参考依据准确 | 分离恒定特征与时变状态，删假观察，不扩大磁盘搜索 |
| 静态关键帧 | 一个成片时刻、对应镜头状态与资产；高度口径与可见尺度参照一致 | 拆互斥时刻，重写姿态、接点或绝对高度/相对高差 |
| 精简执行稿 | 本段规则/资产、独立起终态、段内时码与当前窗口齐全 | 展开“同上”，删全场未来结局、完整重复 beat 和工程说明 |
| 代价与不可逆项 | 双方是否都有支出，至少一项收不回；误判是否真的损失了东西 | 给赢的一方也记代价，写出它此后限制哪个动作，终态保留 |
| 对手能动性与变招 | 对手有自己推进的目标，全场至少一次据已察觉信息改打法 | 补变招拍及其前因依赖；删“不作为规避依据”这类替对手放弃行动的声明 |
| 节奏对比与呼吸拍 | 是否有不出新攻击的窗口；镜长和镜内子拍是否按动作需要分配 | 补呼吸拍且不与关键转折重叠，按动作重分窗口长度，拆掉等分 |
| 光照归属 | 每镜主光写了来源与归属，转折处是否换人照亮 | 逐镜改写光源与暗部；持续光束要影响它经过的岩壁与人脸 |
| 段界可复现交接帧 | 段界是否停在半动作上，交接静图能否独立复现 | 把段界移到短暂稳定的瞬间，补交接帧，提示词不写内部 ID |
| 战场痕迹累积 | 痕迹有来源拍，至少一项先于最早转折，且此后真的限制路线 | 把痕迹接进后续选择或删掉；决胜时刻引用已存在的地形改变 |
| 所知/实际一致性 | 判断与真实分列，线索先于识破出现，主客观镜头可分辨 | 补早于识破的线索，重排识破拍，改写混淆主客观的机位 |
| 生成风险与保底构图 | 复杂接点、多人同框、器物文字是否标了风险并给了更省的保底 | 为高风险镜补遮挡/短窗口/单主体/接点特写，不改剧情、不写时码 |
| 平台与证据 | 品牌未被当作版本/入口/模式，能力与媒体状态有来源 | 交通用稿及待核项，分别记录已生成、已读与未知 |

不以分数、百分比或“保证可生成”代替判断。篇幅建议见入口；按复杂度取舍，保留让动作成立的信息。

复杂接点或用户要求自审时，可围绕实际稿件自问：这只手是否空闲、承力点在哪里？前一镜真的把人或物送到这里了吗？风、衣发与局部冲击的方向有来源吗？静帧的高度是绝对值还是高差？答案指向具体状态、行动或待核证据；找不到就修正文，不用“已检查”代替回答。普通交付不必附整套问卷。

## 数值交叉复算

坐标、秒数和米数一旦进正文就互相牵连，字段各自自洽不等于算得对。本包 v1.2 的审阅漏掉了下列真实错误，这一遍专为它们存在：

- 同一路线上的速度前后矛盾：脉冲一 4.47 米走 3 秒约 1.49 米/秒，脉冲二同线路约 2.24 米/秒，蓄压时间从 4 秒变 11 秒且无解释。
- 已登记为“整张炭化”的符，10 秒后仍被写成可以“烧透残角”。
- 关键帧状态写 y=6、提示词写“北闸前两米”，而北闸在 y=7.6，两者差 1.6 米。
- 资源账目把险过写成算准：风骨 12 秒点燃、束轴 14.6 秒才接上，空烧 2.6 秒；18 秒耗尽对 17.97 秒结束的威胁，余量 0.03 秒。
- 2 米高屏障与 1.2 米高的剑几乎同一 x 位，机位却是腰高中景，注释只保证不遮落脚、没管主体被挡。

复算方式：不采用正文结论，按已写的坐标与时刻独立重算每一处距离、速度、高度和消耗，再逐项回对。结果写成具体修正或待核项，不记“数值已核对”。

- 同一段路线上速度处处一致；变了就写出原因。
- 每件消耗品按时间线查状态：登记为耗尽、炭化或折断之后，不能再出现一次可用。
- 绝对高度与相对高差分别核，两套口径不混用。
- 凡写“算准”“刚好”的地方复算余量；0.03 秒按险过写，不写成从容。
- 机位到接点之间每个遮挡物都查主体是否被挡，不只查落脚点。

## 常见故障与修复

- **敌人停着等招、反派炮塔化**：对手固定在一个坐标重复同一招、失手后不重新锁定、能力够用却被声明“不作为规避依据”时，查目标、信息与动作占用，给他一个独立推进的任务和一次据所见的变招；主角的生路改由遮挡、介质、代价或同伴掩护提供，不必额外安排受伤。
- **零代价收场**：双方无新伤、器物无损、符未耗尽，全场最重的损失是一道划痕。按归属补支出，至少一项不可逆，并写出它此后限制哪个动作；弃剑诱敌就不能让剑完好归掌。
- **越境反杀没铺垫**：依用户规则补地形、介质或任务条件的早期证据；规则不允许时指出与指定结局的具体冲突。
- **飞剑重复或瞬移**：分别追踪实体、剑气和残影，补回程或删多余实体，同步持剑手与护身空档。
- **节点断而控域不变**：按有效规则改变结果，不能只改颜色。
- **痕迹只结算不互动**：焦痕、积水、碎石登记完就再无人提。让至少一项痕迹的来源早于最早的转折，并在决胜时刻限制路线或改变后续效果。
- **跨镜重复命中**：导演层保留完整 beat，执行层只写当前窗口；接触只发生一次，后镜从受力后续接起。
- **慢镜期间另一方做完一套连招**：回到同一世界阶段同步各方；不是把没入画者按成片时长自由推进。
- **时长不足**：删重复拍、简化支线和能力，保留必要准备、移动、反应与对白。
- **镜长等分无呼吸**：出现 6/6/6/6 镜长或镜内 0–3/3–6 这类精确对半时，按动作需要重分窗口，并补一个不出新攻击的呼吸拍，不与关键转折重叠。
- **镜界或段界断裂**：重写具体世界状态，逐字同步相邻镜及段首尾，执行简版也同步；机位另写。
- **段界停在半动作上**：段界落在“刚被贴住”“刚接入”这种瞬间时，移到短暂稳定、轮廓可读的瞬间（呼吸拍通常合适），补归属前段末镜的交接帧，提示词写成可独立复现的完整静图。
- **稳定锚点锁死动作**：把持物手、姿势、当场伤损移至当前状态；不要把资产图姿势或`states`里的未来变化灌入每段。
- **巨物或高差失真**：先统一零点与脚底/盘面口径，再写同框参照；相对高差不能替代绝对高度。
- **静图包含连招**：钉一个接点或姿态，其他时刻分帧或留视频。
- **奇观没有力量感**：补人物签名、可见压力、明确接点或余波，按画风选手法，不机械增加爆炸。
- **全场一句光照复制到底**：“晴冷侧光”贴满每镜时，逐镜写明主光来自谁的能力或环境、谁被压成暗部，转折处换来源或换归属。
- **参考文件失败**：只核对精确路径及直接父目录，记无法读取并继续；未读图不编五官、衣纹和佩饰。
- **执行稿泄漏导演信息**：删依赖 ID、观看任务、未来结局与非本段资产百科；保留当前实际状态和必要规则。
- **把算术自洽当成编舞**：字段齐全、时码连续、ID 有效，不证明速度一致、消耗品还在、主体没被挡，也不证明有对比和代价。结构校验通过后仍走数值交叉复算和本节自检。

## 局部修改的传播

以稳定 ID 定位，先记用户要求保留的终态、总时长、资产和规则；条件冲突时给具体最小调整，不静默改硬要求。

| 修改起点 | 必查影响 |
| --- | --- |
| 规则/施术条件 | 相关行动、反制、结果、窗口及使用规则的本段上下文 |
| 目标/伤势/能力 | 动机、可执行动作、持物/专注占用、后续世界状态 |
| 资产/器形/参考 | 锚点、接触与尺度、相关镜头和帧、本段执行资产 |
| 路线/攻击方式 | 并行支线、对手回应、路径时间、起终态和帧姿态 |
| 时长/分段 | 成片覆盖、cue 窗口及段内换算、共享状态、帧归属 |
| 机位/光效/画风 | 可见资产、左右、遮挡、辨识与帧构图；必要时反查可读性 |

按“动作与结果 → 镜头与共享状态 → 帧 → 执行稿”更新；更改切口同步前镜终态、后镜起态、段首尾及执行版共享文字。保留无关 ID，不另造复杂边界编号。交付可直接使用的更新内容及必要影响摘要，不只列问题让用户自行修复。

例如把正面格挡改侧闪，原格挡导致的腕伤不能无来源保留；应同步飞剑路径、后续伤腕相关动作、相邻状态、关键帧和执行稿。固定总时长时重排窗口，不等比缩放全部数字。

已有媒体不会随提示词改动自动更新。标清哪些图/片段依赖旧稿、待重生成或人工修补；没有对应执行证据时不声称成片已修好。

## 分开记录结构、语义与媒体证据

- **文字语义审阅**：评价已写条件、行动和状态是否自洽，说明修复依据；不证明生成器会执行。
- **结构校验**：用户要求 JSON 时按 [delivery-contract.md](delivery-contract.md) 使用实际存在的验证/导出方式。记录是否运行及真实结果。字段、ID、时间覆盖、字符串相等通过，都不能证明战术合理、空间可达、姿态正确或画面连贯。
- **图像观察**：实际读取后检查可见身份、器物数量、接点、尺度、伤损和构图；不把一张图外推到全片。
- **视频/声音观察**：明确读到哪一片段、是否连续播放、是否实际读取音轨；只评观察到的动作和同步。静音预览不能证明声音正确，单帧不能证明时序连续。

媒体状态按证据逐项记录，不用固定的“未生成”结论：

| 已有证据 | 合理记录 |
| --- | --- |
| 只写提示词，没有生成结果或生成报告 | 本次仅完成文本；媒体是否另已生成未知 |
| 用户说已生成，但当前文件不可读 | 据用户报告已生成；未读取，质量待观察 |
| 工具实际生成成功但未查看 | 已生成，有对应来源；尚未读取，内容未验证 |
| 已读取部分图或视频 | 已读取具体来源/窗口；结论限已观察范围，其他未知 |
| 明确有生成失败或本次未执行记录 | 记录实际失败/未执行动作，不推断其他来源也未生成 |

JSON 存档可用 `review.media_observations` 逐项写 `{source, kind, observation, limitations}`，只用契约已有类型和值；`source` 标明文件、用户报告或工具结果，`observation` 写真实所得，`limitations` 写未覆盖部分和读取限制。它是作者证据登记，不使脚本语义状态自动通过；不另加状态、世界时间或评分字段。

## 紧凑审阅摘要

> **范围与依据**：全场/指定对象；本次审阅的文字、实际读取素材及来源。
>
> **已修**：问题 → 修复 → 受影响对象；无修复时写未发现影响成立的问题，不宣称绝对无错。
>
> **待核与失效项**：真实影响结果的假设、入口参数、不可访问素材及旧产物；没有则省略。
>
> **验证范围**：文字审阅；结构校验是否实际运行；媒体生成依据、实际读取范围与未知部分。未生成/未读/未知分别按证据表述。

摘要简短，修订正文放对应交付部分；先一次覆盖全场六件套，再按用户需求扩写。无需为普通交付额外开启模型测试、联网或审批循环。
