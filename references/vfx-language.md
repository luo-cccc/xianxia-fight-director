# 特效语言：谁的、显示什么、花掉什么、怎么做

特效不是装饰层，是战斗信息的载体。设计任何一个效果先回答四问，答不出的效果删掉或降为环境：

1. **谁的**：归属哪个角色、器物、阵法或环境。无主的光爆不能参与因果，也不能登记光照归属。
2. **显示什么**：它让观众读到哪一条信息——位置、方向、余量、规则、受伤、所知与实际。只为“好看”而存在的效果，最多一处，并让它同时承担节奏。
3. **花掉什么、留下什么**：支出进 `cost`，残留进 `scene.attrition`；不收费、不留痕的大招等于没发生。
4. **怎么做**：一次生成、分层合成还是资产化复用。制作路线决定它跨镜能否保持同一外观。

## 八组特效

按承担的信息分组，不按元素分组。同一个效果可以跨组，但设计时先认定它的主职能。

| 组 | 承担的信息 | 典型 | 常见失误 |
| --- | --- | --- | --- |
| 攻击 | 方向、速度、命中与否 | 剑气、符火、雷击、掌风 | 只有光没有接点与后果 |
| 防御 | 承受、偏转、破裂的过程 | 护罩、剑幕、阵壁、法衣 | 一律完美格挡，不显示损耗 |
| 位移 | 起点、路线、终点 | 御剑、遁光、缩地、瞬移 | 中段没有地标，距离不可读 |
| 计量 | 剩余资源 | 剑身亮度、符数、阵眼明灭、呼吸白气 | 计量与实际消耗对不上 |
| 规则 | 本场能力边界 | 结界边缘、禁空、领域、神识半径 | 规则只写在设定里，画面看不到边界 |
| 状态 | 伤损、透支、中术、增益 | 经络发亮、裂纹、黑气、灵力外溢 | 状态出现后再无后续引用 |
| 空间 | 意识空间、幻境、维度切换 | 识海、梦境、幻阵、洞天 | 与外层混淆，或让外层暂停 |
| 环境 | 战场被改变 | 碎石、积水、焦痕、云缝、霜槽 | 只是背景，不约束任何路线 |

计量组最容易被忽略也最划算：把“还剩几次”做成看得见的东西，观众就能自己读出后面的选择为什么成立，不需要台词。

## 两层：世界内与呈现层

`layer` 只有两档，按“它是否存在于角色的世界里”判定：

- **world 世界内**：角色看得见、碰得到、会被它改变。剑气、护罩、雾、云茧、识海里的白剑都是世界内——识海对它的主人是世界。
- **post 呈现层**：只存在于镜头和剪辑里，角色感知不到。暗角、速度线、色调偏移、画面墨晕、顿帧闪白都是呈现层。

呈现层不进入世界，所以**不能有接触，不能留残留**；会改变世界的效果一律登记为 world。世界内效果必须写残留或消退，说明它离开画面后留下什么。这是结构校验项。

判断不了时问：如果把这一层从成片里拿掉，角色的处境会不会变？会，就是 world。

## 尺度

`scale` 四档，决定构图和参照物，而不是威力：

| 尺度 | 范围 | 构图要求 |
| --- | --- | --- |
| micro 微观 | 器物表面、皮肤、眼睛 | 特写；需要先建立它属于谁 |
| body 个体 | 一个人或一件兵器周围 | 中景；身体支点与受力可见 |
| field 场域 | 一片战场、一座阵、一段空域 | 全景；人物与地标作尺度参照同框 |
| heaven 天地 | 天象、山河、整片云海 | 大远景；必须有人物或建筑的小剪影证明尺度 |

尺度越大越需要参照物同框；天地级效果没有人物剪影，观众只看见一张壁纸。

## 生命周期

每个签名特效按阶段写，`release` 必填，其余按需：

```text
omen 征兆 → release 释放 → travel 传播 → contact 接触 → result 结果 → residue 残留 / fade 消退
```

- **征兆**是给观众与对手的预告。对手据征兆变招，就是 `adaptation` 的依据。
- **传播**写路径与速度，不追踪、会转弯、可被遮挡都要说明。
- **接触**写作用点与介质回应：护罩凹陷、水面压出坑、云被齐整劈开。
- **结果**写形变、断裂、位移或材质改变中的至少一项。
- **残留**进 `scene.attrition`，要在后续镜头里被踩到、被点燃或被借用。
- **消退**写它怎样离开，避免效果“凭空消失”。

阶段文本进可复制执行稿，所以不写数字秒码和内部 ID。

## 签名特效

一场里反复出现、或承担叙事功能的效果登记进 `vfx`，跨镜保持同一外观：同一形状、同一运动方式、同一消退。外观变化本身应有意义——剑气第二道比第一道更细更暗，告诉观众这是最后一道。

不需要把每一点火星都登记。判据：观众需要在第二次出现时认出它，或者它的变化承担了信息。
