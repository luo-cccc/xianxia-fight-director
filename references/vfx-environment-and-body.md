# 环境、介质与身体：特效落在哪里

效果的可信度来自它落到的东西。同一道剑气，劈在空气里是一道光，劈在云海上是一道不合拢的缝，劈在水面是一道压下去又弹起的槽。先选介质，再写效果。

## 介质反应

| 介质 | 受力时的可见反应 | 可留下的痕迹 | 可借用的后续 |
| --- | --- | --- | --- |
| 云、雾 | 被推开成环、劈成缝、卷成涡 | 云缝、空洞、凹陷 | 视线遮挡、穿云转场、藏身 |
| 水 | 压出凹坑、溅起水墙、波纹外扩 | 积水、湿痕 | 导雷、反光、倒影、滑倒 |
| 石 | 碎屑沿受力方向飞、裂纹沿旧伤扩大 | 碎石、裂口、凹坑 | 落脚不稳、遮挡、投掷 |
| 木 | 撕裂、劈开、焦黑 | 断木、炭化 | 引火、翻倒、卡住兵器 |
| 金属 | 硬边反光、弯曲、崩口 | 缺口、凹痕 | 反射光、刃口变钝 |
| 冰霜 | 霜面蔓延、碎裂成片 | 霜槽、冰面 | 打滑、凝住动作、融水 |
| 火 | 被气流压低又窜起、沿可燃物蔓延 | 焦痕、灰烬、持续火墙 | 隔断路线、接管主光 |
| 沙尘 | 被冲击扬起成环、随主风飘散 | 沙坑、扬尘 | 遮挡视线、暴露脚印 |

介质的连续性比效果本身更容易出错：云缝劈开后要一直留在头顶，积水不会在下一镜自己干掉。痕迹登记进 `scene.attrition`，写清它此后限制什么。

## 天象与场域

天象级效果（雷云、日蚀、风暴、天河倒灌）往往不属于任何一个角色，而是被双方争夺或借用。登记时 `owner` 指向场景资产，并在节拍里写清谁在借它、借的代价是什么。

- 天象改变全场主光，是光权易手最大的一次机会，最好放在关键转折。
- 天象要有边界和节奏：雷泽每隔一阵闪一次，比一直闪更有用——间歇闪光能把人物影子投到云底上，自带时间感。
- 天象不随角色意愿开关；借用它的人要付出暴露位置、灵力透支或引火烧身的代价。

## 身体反应

效果作用到身体时，写身体如何承受，而不是写伤害数值：

- **卸力**：哪只脚滑移、哪个关节弯曲、衣摆向哪边甩。
- **透支**：经络发亮、皮肤下灵光外溢、呼吸白气变色、鼻下见血。透支状态要在后续镜头持续。
- **受伤**：伤口位置要与攻击方向一致；兽形的伤与人形的伤在同一侧。
- **中术**：眼神、动作节奏或瞳孔的变化，比周身黑气更可读。

身体反应的位置、侧别在反打后保持世界坐标，不随画面左右翻转。

## 计量外显

把看不见的资源做成看得见的东西：

| 资源 | 外显方式 |
| --- | --- |
| 灵力 | 剑身亮度、法衣纹路明灭、护罩厚度 |
| 次数 | 符纸张数、剑匣剩余剑、铃声次数 |
| 神识 | 呼吸白气的长短、扫查涟漪的半径 |
| 体力 | 呼吸节奏、肩线起伏、落地时膝盖弯曲的深度 |
| 时间 | 香头长短、阵眼逐个熄灭、燃烧的符纸 |

计量要单调：亮度只降不升，除非有登记过的补充来源。计量与 `cost` 的消耗时间线逐镜对账，这属于交付前的数字复算。

## 遮挡物的来源

遮挡是特效与转场共用的工具（见 [transitions.md](transitions.md)）。遮挡物必须来自世界：剑气劈开的云壁、炭火扬起的灰、破茧时崩散的碎云。凭空出现的一团白雾既不可信，也会破坏连续性——下一镜那团雾去哪了？
