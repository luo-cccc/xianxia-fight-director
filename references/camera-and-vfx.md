# 镜头、特效与执行稿：让力量可读且可拍

## 先定主要信息，再选镜头

先确认世界起态、本窗口实际行动与回应、可抵达的终态，再选择机位展示这些事实。换景别或反打只改变观察方式，不能替角色补完回收、落脚或换手。

导演可以简记本镜要让观众读到什么，如封路、实体剑位置、借水导雷或节点失效。不强制每镜写一条观看任务；明确时直接用画面表达。观看任务留导演稿，不复制到生成执行稿。

| 需要读到的信息 | 可用表达 | 保留的证据 |
| --- | --- | --- |
| 战场/空域 | 可读地标的全景、俯视或侧向层次 | 双方、目标物、出入口、高差 |
| 攻防接点 | 双人中全景、侧向机位 | 攻击线、防线、落脚与避让路线 |
| 施术条件 | 手、器物或介质近景，再接回空间 | 来源、印诀、节点或传播路径 |
| 速度 | 稳定地标、掠过前景、方向清楚的跟随 | 起点、方向、终点或截击位置 |
| 巨物 | 人/建筑尺度参照和上下层次 | 接触面、覆盖范围、实际距离 |
| 反制 | 条件先于效果的揭示 | 谁察觉、做了什么、原术何处失效 |
| 谁占上风 | 主光易手、暗部归属改变 | 光源属于谁的能力、谁被压成暗部 |

一镜可以完成一次攻防或多次动作，不按攻击次数切镜。连续近景可有力，仍需保留必要空间证据。高燃画面与画风方法按需读 [spectacle-and-style.md](spectacle-and-style.md)。

巨物的必要尺度参照要与主体同框可见，或通过连续运镜建立两者关系；只在文字里报出高度，构图却看不到人物、门柱或地标，不能证明尺度。近大远小可以强化压迫，但不改变双方实际距离和攻击可达范围。

## 空间与运镜

用战场地标固定方向、主要交战轴和高度层。画面左/右仅属于当前机位；切反打不让人换战场位置、持剑手、受伤侧或飞剑方向。

跨轴可用可见绕行、居中/俯视或重新建立位置交代。御空同时说明水平路线、高度和上下危险；追逃用起点、转折地标、截击点与出口形成路线，不靠摇镜掩盖距离。

接触或机动决定结果时，让镜头看清身体支点、力的传递和对手回应：哪只脚、手或飞行器承重，力量经哪里到达接点，另一方退让、转肩还是继续承力。起态中的悬空脚要有落点，终态中的跪地、侧移或失衡要由当前窗口产生；不必为无关细节另设栏目。法术提供额外支撑时，展示本场已有的供能或受力依据。

运镜写目的、方向、停止点，如“侧向跟甲退至断柱，停在能看清飞剑回弧的位置”。高速动作叠复杂运镜时，确认接点可辨；稳定机位、固定前景或减少一项并发常比再加形容词有效。镜头不无故穿过实体地形。

慢镜用于值得读清的选择、危险接点或情绪感知；写成片窗口、世界动作阶段及各方同步，不让攻击者因特写无理等待。帧率未核实就不写高帧率承诺。顿帧、速度线、形变及声音抽离的适用条件见画风参考。

## 长镜、窗口与剪辑点

镜头是剪辑单位，生成窗口是一次生成的时间窗。一个窗口可以只含一镜，也可以含多个剪辑点；窗口边界允许落在镜头中部。写执行稿时不要把一个窗口拆成互不相关的镜头块：先写“本窗是连续生成窗口，镜头之间是剪辑点，不重新起手”，再按时间顺序写动作、机位、光与声。

- **连续长镜**：写机位路径的起点、途经点、停止点与焦点变化；写谁在承重、谁被前景遮挡、光从哪一侧进入。不要用“镜头跟随”代替具体路径。
- **窗口内剪辑点**：每个剪辑点写清保留什么（人物位置、朝向、持物、前进方向、光权、声底）与改变什么（景别、机位、空间）。硬切是默认；需要遮挡或转场载体时，载体必须来自世界。
- **窗口边界**：入口写机位位置、镜头、高度、运动矢量与银幕方向；出口写下一窗能接上的机位状态。跨窗不换轴线；换轴要可见绕行或重新建立位置。
- **光与声跨窗**：主光来源与归属、环境声底、音乐状态、对白音色写进接缝包。窗口内光权易手时，写清由谁的能力或环境改变，并在该窗口内给一个可读瞬间。
- **post 效果不进生成**：暗角、速度线、墨晕、顿帧闪白能在后期加的，不写进生成提示词；它们跨窗会消失，也不能当接缝。慢镜变速留在同一窗内，或切在变速起止。

窗口规划的方法与切点分级见 [window-planning.md](window-planning.md)。

## 光照与归属

仙侠战斗的光源多半就是双方的能力本身：剑光、符火、阵眼、霜束。此刻画面被谁的光照亮，是一个免费的戏剧变量，可直接用来登记优劣势。

每镜 `light` 登记三件事：主光来源、它属于谁的能力或环境、谁被压成暗部。例如“霜束自左上贯入，照亮乙的扇面与下颌；甲退进束后背光，只剩轮廓和腰侧银痕”。转折处主光要改变来源或归属：原先照亮对手的光转而照亮自己，或主光由术法交回环境。全场 `light` 不得完全相同，这是结构校验项。把“晴冷侧光”复制进三个段头、战局已翻转而光不动，等于没有登记光照。

大体量持续效果必须照亮它经过的表面和近处的脸。两米粗、横贯四十米的霜束，若岩壁没亮、莲台没返冷光、没有一张脸改变受光面，这是连续性漏洞，不是克制。反光、逆光、光色与色温按材质给：湿石回高光，金属出硬边，霜雾散成体积光，符火把暖色压上冷调环境。亮暗先服务画面层级，不要只当“左晶暗右晶亮”式的电量读数。

`execution.light` 另写本窗口的精简光照，与起终态同栏进逐段执行稿；它和 `fallback` 一样不写数字秒码与内部 ID。外层 `light` 属完整导演稿，与 `camera/effects/sound` 同级，可以写全场时码。光束是否真照亮了它经过的表面、转折处主光是否真易手，属语义审阅。

## 效果的识别语法

以少量形状、运动、材质、发光位置和消退行为建立区分，颜色只辅助：

- **实体飞剑**：器形、柄护手和硬边稳定，尾迹不是额外一柄剑。
- **剑气**：边缘、厚度、方向及消散区别于实体，受阻后明确偏折、破开或溃散。
- **残影**：透明度、滞后和边缘可辨；碰撞能力按本场规则。
- **符箓元素**：先有载体与启动证据，再沿已确立的介质传播。
- **阵法**：节点、连接、边界和失效方式一致，毁掉的节点不自动恢复。
- **幻术**：标明主观或客观视角，异常可回溯，真实状态仍留导演记录。
- **法相巨兽**：轮廓和尺度参照稳定，实体接触与能量穿透分开表达。

效果写“来源—传播/覆盖—作用点—身体或环境回应—残留/消退—消耗什么—留下什么”。光效之外要有结果：护罩偏转、破裂还是穿透？手臂如何卸力、脚底是否滑移，烟尘之后人物在哪？按受力选择器物弯曲、碎屑偏移、水面波纹或落脚变化，不要求每次命中都损伤人物或破坏地面；强光也不代替接点与后果。

每个效果声明它花掉什么、留下什么痕。消耗写具体支出（三张符、扇骨一处缺口、灵力透支后不能再御空），账目进 `cost`。留下的痕进 `scene.attrition`，并写明它此后如何限制路线或与后续效果互动：白霜槽让横移打滑，炭化符位置贴不上新符，积水让雷术覆盖扩大。至少一项痕迹的来源节拍要在最早的关键转折之前结束，这是结构校验项；地形先被改变，才谈得上约束决胜时刻的选择。

场上维持一层会累积的东西（水、尘、炭、碎石、霜），之后的效果都发生在这层之上。只记入状态却再不与任何后续效果相遇的痕迹是结算清单；写明“之后不复现”等于宣布这次消耗没有后果。要么它被踩到、被点燃、被借用，要么不必登记。

场景有持续风时，以战场方向固定主风向，衣摆、头发、烟尘和轻物随各自位置、重量作出一致反馈。局部冲击可以暂时改向，但要有来源、作用范围和衰减，之后回到主风或留下真实后果；主风、冲击与法术吸引不要混成无来源的任意飘动。反打后重新换算画面左右，不把镜头左右当世界风向。

### 可读性层级

决胜接点处正面指派层级，而非靠排除项维持清晰：哪一层承载攻击线，哪一层承载回应，哪一层是残留，哪个单独元素最亮、占住视觉重心。其余压暗、减饱和、移出焦点或缩小面积。主次随受力换手：攻击线最亮时回应层压暗，结果一旦成立，视觉重心移到结果本身（凹陷、断口、被夺走的器物）。

堆叠“无…”不是可读性方案。一张关键帧写出十三条“无…”，说明只有禁令清单、没有层级计划；排除项最多用来排除误读，不能产生主次。

决胜接点必须产出可见事件与后果，至少一项：形变、断裂、位移、材质改变。三十六秒打斗的高潮收在“仅细白石屑和霜雾”，等于这次接触没有结果。“强光不代替接点与后果”的办法是补上后果，不是取消场面。

遮挡制造悬念时，用声音、痕迹、反应或揭示恢复因果。新增大效果复查手、器物、节点和接触点是否被遮住；群战保留阵营与友军安全关系。

### 签名特效与制作路线（1.3 起，1.4 继承）

反复出现或承担叙事功能的效果登记进 `vfx`：归属、世界内或呈现层、尺度、功能、外观、生命周期、支出与制作路线。设计先回答四问——谁的、显示什么、花掉什么留下什么、怎么做——八组分类、两层判法与生命周期见 [vfx-language.md](vfx-language.md)，介质与身体反应见 [vfx-environment-and-body.md](vfx-environment-and-body.md)，制作路线与难度见 [vfx-production.md](vfx-production.md)。变身、飞行与意识空间见 [space-time-and-form.md](space-time-and-form.md)，转场见 [transitions.md](transitions.md)。

## 声音与对白

按本镜需要写环境、动作、施术和接触声；画外事件也须有可感知来源。用材质与机制区分金属碰撞、剑气擦过、符纸燃尽和阵线断裂。音乐跟随用户要求或明确的创作设定，不自动补 BGM。

对白逐句标说话者和发生窗口，与呼吸、受击、结印和高速移动兼容。导演稿可写全场成片时码；执行稿用窗内时码。JSON execution 文本不嵌数字秒码，由 `cues.start/end` 定位。语速不够就压台词或动作，不强塞。

## 导演稿与精简执行稿分离

| 导演稿保留 | 复制用执行稿保留 |
| --- | --- |
| ID、全场成片时码、因果、依赖与完整跨镜 beat | 段内或窗内成片时码、当前窗口实际行动 |
| 全场目标、转折和终态，以及必要观看任务 | 本段适用规则、布局、必要资产锚点 |
| 参考溯源、拍/帧关联、制作分配 | 可独立恢复的起态、终态及参考控制范围 |
| 跨镜动作完整定义与本镜观察窗口 | 本窗口镜头、光照、效果、声音与对白，高风险镜附保底构图 |

执行稿按本段动作密度保留可执行内容。不要把完整导演表照抄成提示词，也不要为了短而只写“接上段”。相邻镜的执行版终态/起态逐字共享同一世界状态，世界状态与机位分栏。

例如导演 beat 是“甲起手、劈中护罩、罩面凹陷再破裂”，本段从已接触处开始，执行稿直接写“剑刃已压在罩面，甲继续下压，凹陷沿旧裂痕扩大”；不再写抬剑起手，不重复伤害，也不提前写几段后的敌方死亡。角色此刻选择用行动和可见征兆表达，不把“观众需理解”“依赖 B03”塞入执行文本。

### JSON 对接

字段与时间规则统一见 [delivery-contract.md](delivery-contract.md)，按存档声明的版本填写。镜头执行窗口由作者按当前相位另写，不能把跨镜完整动作自动截成执行稿；段上下文只保留本段适用条件。有 1.4 窗口规划时，05 按窗口输出，窗口内的镜头是剪辑点；入口/出口静帧、接缝包与降级切点随窗给出。上述支撑、受力和环境信息放入既有状态、行动、摄影或效果文字，不新增字段。本节的光照、累积痕迹、生成风险在 1.2 分别对应镜头 `light`/`execution.light`、`scene.attrition`、`risk`/`fallback`，关键帧角色 `role` 同见该契约；1.4 的窗口字段同见该契约与 [window-planning.md](window-planning.md)。精确双时轴、重放、插叙另用自然语言说明或明确扩展需求。

## 生成风险与保底构图

`risk` 取 `low | high`。判据是**这一镜是否承载全场别处没有的那一件事**，而不是难度：决胜接点、巨物尺度的唯一同框参照、信息差揭开的那一下、关键机制的唯一一次交代，标 `high`。内容在别处也有或可以重新编排的，标 `low`，哪怕技术上同样不容易。过半镜头被标 `high` 说明在量难度，回头重标：普通短场通常只有一到三镜真需要预授权退路。

`high` 必须附非空 `fallback`，`low` 不得附。保底构图写同一份世界状态下更省的呈现方式，不改剧情、不写时码：

| 本镜难点 | 可用保底构图 |
| --- | --- |
| 多体接点同框 | 接点特写加画外声，身体关系由前后镜承担 |
| 相似面孔同框 | 过肩或背身，只露器物、衣饰与一侧轮廓 |
| 器物文字符号 | 大面积遮挡，只亮出可辨认的一角 |
| 长连续动作 | 缩到起态与终态各一个可读瞬间，中段交给声音与痕迹 |

换的是观察方式，不是事实：起终态、持物、伤损、在途攻击与痕迹一律不变，所以它能作为一次生成失败后的现成降级路径进执行稿而不破连续性。降级后仍要留住本镜必要证据；某种保底会丢掉唯一的攻击线或支点，就换一种。

本项不写任何平台品牌、版本、入口或模型名，平台相关的未证实内容按下节记待核项。

## 平台适配只依证据

用户只给品牌，不默认具体版本、网页/API 入口或工作模式。先交平台无关稿；不为写通用稿强制联网。确需适配时优先用用户当前界面/文档及对应官方来源核实，只修改已证实的时长、参考入口和控制项。未知项目列为待核，不套传闻参数。

第三方教程可以作线索，不能证明用户当前入口实际能力；官方说明也要注意版本和入口适用范围。入口限制导致拆镜时，同步成片时间轴、关键帧和共享状态。实际生成、读取和观察结论分别记证据，不把文本可执行性称为成片成功。
