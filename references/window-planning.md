# 生成窗口规划：按内容定界，按能力取级

窗口不是一段时长，而是一份可独立执行的契约。先读剧本的关联结构，再决定哪里切；平台上限只决定这张切点表用到第几级。**不设通用时长，不默认任何平台参数。**

## 窗口是一份契约

- **前置条件**：入口状态、接缝包、参考包。
- **后置条件**：出口状态、接缝包。
- **不变量**：身份锚点、画风、地理、物理规则、银幕方向、光逻辑、声底。
- **函数体**：本窗动作、镜头、光、声、特效。

判断一个时刻能否成为窗口边界，只问一句：**拿走前一窗的像素，只给这份契约，一个没看过前文的人能不能生成出接得上的这一窗？** 能，边界成立；不能，说明某条关联还没被写进契约。

同一动作线内，前窗 `closing_state` 与后窗 `opening_state` 逐字相等；跨动作线的边界不要求相等，由内景镜头的 `outer_state` 与外层状态接续。窗口状态是供执行稿使用的精简状态，须与导演层镜头状态一致，但不要求逐字相等；落在镜头中部时，用窗口自己的状态采样，不强行改写镜头状态。

## 三层关联

| 层 | 定义 | 处理 | 例子 |
| --- | --- | --- | --- |
| **硬结** | 拆开就坏，靠入口包写不回来 | 必须同窗；超过上限就改设计，不硬拆 | 慢镜回召与钩口咬住；化形茧内；巨物与人的唯一同框；连续长镜里的空间证明 |
| **携带** | 可以跨，但必须写进入口/出口包 | 结构化 `carries` 加状态文本 | 伤腕、剑缺口、灵力亮度、所知、主光归属、声底、地形痕迹 |
| **自由** | 拆开不影响因果、识别、受力 | 按 A/B 切点切 | 建立镜头、反应镜头、余波空镜、重复试探 |

簇是约束，窗口是决定。一个窗口可以包含多个簇和一段自由内容；一个簇也可以只占窗口的一部分。不要把簇直接当成窗口，否则窗口长度会被簇长度绑死。

## 关联类型

| 家族 | 关联 | 判断问题 | 处理 | 破坏后的症状 |
| --- | --- | --- | --- | --- |
| 物理连续 | 连续动作/在途物 | 边界两侧是否同一式未完成？ | 硬结；拆则写 C 级相位包 | 剑瞬移、换手、速度突变 |
| | 资源计量 | 是否跨阈值？ | 边界放在阈值一侧；携带数值 | 剑光回升、符数变多、伤腕忽然能握 |
| | 地形痕迹 | 边界前形成的痕迹是否影响后文？ | 携带；后文必须互动 | 地面忽然干净、积水消失 |
| | 形态阶梯 | 变身是否在边界内？ | `occlusion`/`morph` 硬结；`cut` 可作边界 | 变身后认不出、伤口换侧 |
| | 尺度同框 | 巨物与人的唯一同框是否跨边界？ | 硬结；同框必须一帧 | 巨物变小、人物消失、比例漂移 |
| | 光权 | 主光是否在边界处易手？ | 易手处是 A 级切点；携带新光源 | 光突然换向换色、暗部归属乱 |
| | 连续运镜 | 机位是否在同一运动中？ | 硬结或改机位；携带路径 | 机位跳变、轴线翻转 |
| | 地理/高度 | 路线、高差、出口是否跨边界？ | 携带地图；新空间首镜重定向 | 高度漂移、出口位置变 |
| | 天气/风 | 主风、雨雪是否跨边界？ | 携带方向与强度 | 风向反转、雨停、衣摆反飘 |
| | 服装/道具 | 湿损、破损、持物是否跨边界？ | 携带状态 | 湿衣变干、缺口消失、持物换手 |
| 因果/信息 | 因果链 | 因与果跨边界时，果能否从入口状态读懂？ | 能则携带；不能则硬结 | 结果无因、对手突然全知 |
| | 信息链 | 线索与识破跨边界时，观众是否已看见线索？ | 已看见则携带；未看见则硬结 | 识破无线索、观众看不懂 |
| | 角色认知 | 边界处角色是否刚改变判断？ | 可携带“他以为/他已识破”；瞬间是重点则硬结 | 表演与所知不符、反应提前或滞后 |
| | 不可逆代价 | 边界前发生的不可逆项是否仍限制后文？ | 必携带；终态保留 | 剑完好归掌、伤腕复原、符又出现 |
| | 时间压力 | 倒计时、燃烧、关门是否跨边界？ | 携带剩余时间；不切在阈值中 | 倒计时重置、香头变长 |
| 空间/时间线 | 动作线切换 | 世界与内景是否跨边界？ | 转场作边界；不在内部切 | 外层暂停、内景无出口 |
| | 旁支/画外 | 画外角色、并行线是否跨边界？ | 携带其进度；首镜给证据 | 画外角色消失、支线停摆 |
| | 观众定向 | 新窗口首镜是否知道在哪？ | 首镜重定向；不依赖前窗构图 | 观众丢失方位、以为换了地点 |
| 声音/表演/风格 | 声音 | 声桥、音乐、环境声是否跨边界？ | 可携带声尾；声桥作边界 | 环境声断层、配乐重启 |
| | 对白 | 台词是否跨边界？ | 切在句末或呼吸；携带语速音色 | 半句被切、口型不对 |
| | 表演 | 情绪、决定是否跨边界？ | 携带“刚意识到/刚决定”；瞬间是重点则硬结 | 情绪归零、动机断线 |
| | 母题/色彩 | 视觉母题是否跨边界？ | 软关联；尽量一致 | 色彩跳变、符号丢失 |

## 五步判断

1. **找不可逆变化**：代价、信息、形态、动作线、空间跳变——这些是簇的核心。
2. **找跨镜未完成物**：在途剑、飞行、坠落、持续术法、正在塌的阵——这些是簇的边界。
3. **找唯一信息**：巨物尺度、机制唯一交代、线索到识破、决胜接点——这些不能跨。
4. **找可读切点**：稳定姿态、呼吸、硬切、光声变化、遮挡——这些是候选。
5. **找返修价值**：高漂移、易改稿、贵镜头——这些倾向短窗或单独成窗。

## 切点分级

| 级别 | 条件 | 用法 |
| --- | --- | --- |
| **A** | 稳定姿态、呼吸拍、硬切、光声变化；无在途物；两侧状态完整 | 首选 |
| **B** | 镜头硬切且姿态可读；或世界内遮挡、转场载体能藏缝 | 次选；短上限时用 |
| **C** | 半动作：需相位、速度、在途物、运动模糊、声尾 | 最后手段；高风险并带降级切点 |
| **X** | 形态遮挡内部、动作线切换内部、唯一信息连续镜头内部、尺度唯一同框内部、post 效果内部、慢镜变速中段、台词半句 | 禁止切 |

C 级边界由后窗承担风险：后窗标 `high`，写 `fallback` 与非空 `fallback_splits`。

## C 级接缝包

1. **相位/进度**：动作完成到几成，世界动作阶段。
2. **速度/方向**：每个移动物与身体的速度矢量。
3. **在途物**：位置、朝向、亮度、尾迹、碰撞状态。
4. **身体机制**：支撑脚、重心、可用肢体、持物、伤损。
5. **运动模糊/快门**：接缝帧是否带拖影，方向必须匹配。
6. **遮挡物**：能否用云、尘、器物掠过、反应镜藏缝。
7. **光**：来源、方向、色温、阴影；移动光源的当前位置。
8. **声**：接缝声、声尾、环境声底；不能只写“继续”。
9. **机位**：位置、镜头、高度、运动矢量；连续运镜要写路径。
10. **帧**：接缝帧加一张稍后时刻的帧，或一段短动态参考，否则速度读不出。

> 例：01 的 21 秒切在慢镜回召中段。入口状态须写：剑在缺口内约六成回程、约每秒八米向西北、高 1.2 米；钩口在 (0.9,2.4) 横等；秦砚右手空置、二指仍指；杜彻前脚承重、棍杆横持；第一节点暗、第二节点已暗、第三节点亮；剑脊青光是唯一硬光源；声为剑鸣上扬与窄刃掠风。直出稿第一句不能写“开始回召”，要写“剑已过缺口，继续向西北回程，钩口在等”。

## 窗口长度

| 成本 | 随窗口长度的变化 | 后果 |
| --- | --- | --- |
| 接缝成本 | 窗口越少越低 | 长窗减少接缝 |
| 漂移成本 | 越长越高，约十五到二十秒后加速 | 身份、光、特效、表演漂移 |
| 返修成本 | 越长，一次改稿重做越多 | 长窗贵，但接缝少 |
| 生成成本 | 越长，单次越贵，失败更贵 | 长窗失败一次伤很大 |
| 关联成本 | 拆簇即设计错误 | 不是可交易的项 |

窗口长度取“必须同窗的最长簇”与“能读懂的微弧线”的较大者，再被上限截断；漂移和返修风险高时主动缩短。簇是下限，不是窗口长度；不要为凑上限加内容，不要等分。

- 高漂移内容短窗：变身、复杂签名特效、多人同框、巨物尺度、细碎粒子。
- 高返修内容短窗：客户未定、结局可能改、关键接点要反复试。
- 低密度连续内容可长窗：追逃、飞行、余波、氛围。
- 台词与呼吸按句子和呼吸切，不按秒。

## 接缝包

每个边界过一遍下表，只写真正跨界的项，但判断时必须全看。

| 类别 | 要写什么 |
| --- | --- |
| 世界状态 | 位置、高度、支撑、朝向、动势、可用肢体、持物、伤损 |
| 在途物 | 飞剑、剑气、暗器、坠落身体 |
| 持续术法 | 护罩、阵、幻境、变身 |
| 资源计量 | 剑光、符数、阵眼、呼吸、剩余时间 |
| 不可逆代价 | 已支出项、物理痕迹、此后禁止的动作 |
| 所知 | 谁以为什么、谁已识破 |
| 光 | 主光来源、归属、暗部 |
| 声 | 环境声底、音乐状态、声尾 |
| 机位 | 位置、镜头、高度、运动 |
| 特效 | 每个世界内特效的当前阶段 |
| 形态 | 当前形态、共享锚点、阶梯步 |
| 动作线 | 世界线或内景线、时间关系、外层状态 |
| 观众定向 | 首镜如何告诉观众“这是哪、刚发生了什么” |

接缝包不是状态复述。只写下一窗不知道就会错的东西。

## 特殊结构

| 结构 | 规则 |
| --- | --- |
| 变身 | `occlusion`/`morph` 的整个阶梯必须同窗；`cut` 法可把边界放在切点；阶梯超上限则改方法或压缩征兆，不切茧内。 |
| 动作线切换 | 切换本身是转场，不是簇；边界可放在切换上，但须有世界内载体；内景窗必须带外层状态。 |
| 巨物尺度 | 唯一同框证明必须在一帧一窗内；不能把人和巨物分到两窗。 |
| 签名特效 | 世界内特效跨界要写阶段；`post` 特效不进生成也不跨窗；计量只能单调。 |
| 慢镜 | 不切在变速中段；切在变速起止，或把速度与世界相位写进接缝包。 |
| 对白 | 切在句末或呼吸；半句必须带声尾与下一句起拍。 |
| 音乐 | 切在乐句边界；无音乐要明确写“无配乐”。 |
| 蒙太奇 | 簇是节奏或意念，不是物理动作；可按乐句或呼吸切。 |
| 单窗口直出 | 全片一窗；仍要写切点阶梯作为失败降级。 |
| 超上限的簇 | 直接报“改设计”，不静默拆。 |
| 短于上限 | 一窗；不补内容、不拉长。 |
| 镜头中部起止 | 边界须对齐该镜 `execution` 的 cue 边界；入口/出口状态是权威，首末镜的 execution 起终态只作镜内参考。 |
| 并行线 | 画外线跨界要携带其进度，否则观众以为它停了。 |
| 跨场衔接 | 首窗入口包带上场留下的伤、物、所知、时间、天气；末窗出口包给下场。 |

### 两个容易忽略的细节

**post 层效果不能当接缝。** 暗角、速度线、墨晕、顿帧闪白只存在于剪辑里；下一窗生成时不知道它存在，接缝会跳。要么把 post 效果留在同一窗内，要么在后期统一铺过接缝。慢镜同理：它改变的是呈现速度，不是世界状态；切在变速中段，下一窗不知道该用几倍速。

**观众定向不是模型定向。** 模型只需要入口包；观众需要因果链。一个窗口对模型自足，不等于对观众自足。新窗口首镜要重新给方位、给刚发生的变化、给“现在该看谁”。

## 能力适配

| 能力 | 有 | 没有 |
| --- | --- | --- |
| 上限 | 长窗可行，但仍按内容切 | 短窗，多接缝 |
| 任意起点 | 可只重生成中段 | 顺序生成，接缝更多 |
| 首帧条件 | 入口帧可作条件 | 入口帧只是文档，靠硬切或遮挡 |
| 尾帧条件 | 出口帧可作条件 | 同上 |
| 首尾帧 | `bridge` 缝合可行，C 级接缝更容易 | 避免 `bridge`，优先 A/B |
| 窗口内剪辑 | 一窗可含多个剪辑点 | 一窗即一个连续长镜，用运镜或遮挡 |
| 音频 | 声音进提示词，音频连续性关键 | 声音后期，提示词写“无配乐” |
| 多参考图 | 每窗可带角色、场景、风格参考 | 减少参考，靠文字锚点 |

**能力未知时给阶梯，不给默认值。** 同一份剧本按候选表输出“上限三十秒取哪几刀、十五秒取哪几刀、十秒加哪几刀”。示例中的三十秒只是示例前提，不是全包默认。

### 参考包与音频

每窗要能独立生成，除入口/出口帧外，另备一份参考包：角色与生物的身份参考、场景与关键道具参考、风格参考（画风、色彩、材质）、上一窗的声尾与环境声底、禁止项（不新增角色、不换装、不换光向、不换持物手）。参考只控制对应维度；不写平台专属槽位名，按用户实际入口映射。参考图未读取时只继承用户文字已确认的内容，不编造五官与佩饰。

生成端带音频时，写清环境声底、音乐状态（有/无/段落）、对白音色与语速；跨窗的声桥、余音、静默写进接缝包。无音乐就明写“无配乐”，避免模型自加；音频后期制作时，提示词写“静音/无配乐”，声音另轨。音频不新增 JSON 字段：`capability.audio` 只声明生成端是否带音频，声音状态写进 `carries.text` 与执行稿声音栏。

**余量**：1.4 不登记重叠窗口。需要生成余量时，在两个相邻窗的执行稿里各写明同一段余量的用途与取值，最终在剪辑点只取一侧；余量不改变窗口规划的时间轴，也不进入 `window_plan` 的时间字段。

> 05 的阶梯：三十秒为 0–11 / 11–20 / 20–32；十五秒不变；十秒为 0–5.5 / 5.5–11 / 11–20 / 20–25 / 25–32；六秒在十七秒声桥、二十五秒与二十八点五秒稳定点继续拆。
>
> 01 的阶梯：三十秒为 0–15.5 / 15.5–25 / 25–34；十秒在前段六点五与十一点五处拆；八秒在二十二点五处再拆；六秒时回召簇九点五秒放不下，须改设计而不是硬切。

## 写法

### 03 导演稿

```text
## 生成窗口规划

### 关联簇
| 簇 | 镜头 | 时间 | 类型 | 为什么不能拆 |

### 切点候选
| 候选 | 时刻 | 镜头 | 级别 | 理由 | 接缝方式 |

### 窗口
| 窗口 | 时间 | 含簇 | 入口包 | 出口包 | 风险 | 降级切点 |

### 能力阶梯
| 上限 | 窗口划分 | 与选定方案的差异 |

### 判断记录
- 选定：...
- 被否：...
- 待核：...
```

“被否”一栏记录“某个时刻为什么不用”，防止下一次改稿又从零猜。

### 05 执行稿

每窗分两态：**直出稿**与**返修卡**。直出稿连续写完整窗，镜头之间标“剪辑点”，不写成互不相关的镜头块；返修卡只写入口、出口、接缝包、降级切点，保证只重做这一段时不破连续性。

```text
## 生成窗口 2（成片 11–20 秒）
- 含镜头：4–6
- 入口静帧：...
- 出口静帧：...
- 接缝包：...
- 本窗规则与场景：...
- 资产锚点：...
- 本窗起态：...
- 剪辑点 1（本窗 0–3 秒）：...
- 本窗终态与承接：...
- 本窗生成风险与降级：...
- 返修卡：只改本窗时，入口、出口与接缝包不变；若改关键相位，同步相邻窗与本窗帧。
```

### 06 审阅

- 每个簇是否完整落在一个窗口。
- 每个内部边界是否引用 A/B 候选；C 级是否有相位包与降级。
- 每个窗口的入口包是否足以独立生成，出口包是否足以接下一窗。
- 不可逆代价、所知、世界内特效、形态、痕迹跨边界时是否进了接缝包。
- 窗口长度是否由内容决定，有没有等分或凑上限。
- 每个高风险窗口是否有可执行的降级切点。
- 每个窗口首镜是否给观众定向。
- 有没有把 post 效果、慢镜、台词切在接缝上。

## 校验与审阅的分界

结构上可查：簇是否同窗且时间范围不跨窗口、窗口是否连续覆盖、边界是否引用候选、C 级是否高风险并带降级、入口出口帧是否对齐、上限是否被超过、簇跨度是否超过上限、形态遮挡是否跨界、动作线切换是否有转场、跨界的不可逆代价、所知、特效与痕迹是否进入接缝包、降级切点切完是否仍在上限内。

仍属语义审阅：簇是否真的成立、A 级切点是否真的稳定、接缝包是否足够、窗口有没有微弧、长度是否被内容驱动。

## 修改传播

| 改了什么 | 必须同步 |
| --- | --- |
| 窗口内动作 | 本窗入口出口帧、相邻窗接缝包、直出稿、降级切点 |
| 入口状态 | 前一窗出口状态、边界帧、所有引用该状态的后续窗 |
| 出口状态 | 后一窗入口状态、边界帧、接缝包 |
| 代价、所知、特效阶段 | 所有跨该边界的接缝包与下游窗 |
| 窗口时长 | 上限、资源余量、降级切点、慢镜窗口 |
| 窗口边界 | 候选级别、两侧状态、交接帧、转场保留与改变 |
| 关联簇 | 重新跑簇测试；可能重排窗口，不能只改文字 |
| 平台能力 | 重新适配阶梯，不静默按新上限重切 |

## 常见故障

- **按平台时长切内容**：先定三十秒再塞动作，窗口数和镜长都会露馅。先读关联，再套上限。
- **把携带当硬结**：每窗重复整份状态，执行稿膨胀；或者反过来，把硬结当携带，接缝处写一句“剑仍在回召”就以为接上了。
- **簇跨窗**：最典型的是化形茧内被切、慢镜回召中段被切、巨物与人分到两窗。
- **所有窗口都标高风险**：等于没判断；高风险窗必须有真实降级路径，不是为了保险全标。
- **C 级接缝只给一张静帧**：没有速度、在途物与声尾，下一窗只能猜。
- **post 效果当接缝**：墨晕、暗角、速度线跨窗后消失，接缝跳。
- **新窗首镜不重定向**：模型能生成，观众不知道在哪。
- **等分窗口**：十五加十五、十加十加十，和等分镜长一样，是按时长分配的指纹。
